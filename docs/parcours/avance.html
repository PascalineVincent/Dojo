Statistiques avancées : bootstrap, puissance, tests multiples

Bootstrap de la médiane

Marche 1 sur 4 · Avancé

La médiane n’a pas d’erreur-type simple. Par bootstrap : tire 2 000 échantillons avec remise dans la fécondité des 47 provinces suisses (swiss$Fertility), calcule la médiane de chacun et renvoie les quantiles 2,5 % et 97,5 % (intervalle percentile à 95 %). Place set.seed(1) avant la boucle.

AstuceIndice 1 · par où commencer

Un rééchantillon bootstrap a la même taille que l’échantillon et se tire avec remise.

AstuceIndice 2 · la démarche

sample(x, replace = TRUE) tire un rééchantillon ; l’intervalle attendu est environ [65,5 ; 75,5].

Raisonnement.

  1. Le bootstrap traite l’échantillon observé comme une population.
  2. Pour chaque rééchantillon, on recalcule la statistique (ici la médiane).
  3. Les quantiles de ces 2 000 médianes donnent un intervalle percentile.

Lecture économique. Le bootstrap est le recours standard quand la statistique (médiane, indice de Gini, ratio) n’a pas de formule d’erreur-type simple : il permet de donner des intervalles pour des indicateurs d’inégalité ou de concentration.

set.seed(1) x <- swiss$Fertility b <- replicate(2000, median(sample(x, replace = TRUE))) unname(quantile(b, c(0.025, 0.975))) 
set.seed(1)
x <- swiss$Fertility
b <- replicate(2000, median(sample(x, replace = TRUE)))
unname(quantile(b, c(0.025, 0.975)))

Pièges fréquents.

  • Tirer sans remise : on retrouve toujours l’échantillon d’origine.
  • Oublier set.seed : l’intervalle change à chaque exécution.

Pour aller plus loin. Refais avec 200 puis 5 000 rééchantillons : l’intervalle se stabilise-t-il ?

Puissance d’un test par simulation

Marche 2 sur 4 · Avancé

La puissance est la probabilité de rejeter H0 quand elle est fausse. Simule 2 000 expériences où deux groupes de 20 observations diffèrent de 0,5 écart-type (rnorm(20, 0.5) contre rnorm(20)), applique t.test à chacune et renvoie la part de p-values inférieures à 0,05. Place set.seed(2) avant la boucle.

AstuceIndice 1 · par où commencer

On compte les cas où le test rejette alors que l’écart de 0,5 est bien réel.

AstuceIndice 2 · la démarche

mean() d’un vecteur de TRUE/FALSE donne la proportion de TRUE. Résultat attendu : environ 0,34.

Raisonnement.

  1. On simule le « vrai monde » avec un écart de 0,5.
  2. On teste à chaque simulation.
  3. La proportion de rejets estime la puissance (environ un tiers : très insuffisant).

Lecture économique. Avec 20 observations par groupe, on détecte un effet moyen (0,5 écart-type) une fois sur trois : de nombreux « effets non significatifs » d’études expérimentales en économie viennent de ce défaut de puissance, pas de l’absence d’effet.

set.seed(2) rejet <- replicate(2000, { a <- rnorm(20, 0.5); b <- rnorm(20) t.test(a, b)$p.value < 0.05 }) mean(rejet) 
set.seed(2)
rejet <- replicate(2000, {
  a <- rnorm(20, 0.5); b <- rnorm(20)
  t.test(a, b)$p.value < 0.05
})
mean(rejet)

Pièges fréquents.

  • Interpréter une non-significativité comme une absence d’effet.
  • Oublier que la puissance dépend de n, de l’effet et du seuil.

Pour aller plus loin. Passe à n = 50 par groupe : la puissance double environ.

Corriger les tests multiples

Marche 3 sur 4 · Avancé

On a 18 p-values : 15 tirées au hasard (runif(15)) et trois petites (0,0004 ; 0,002 ; 0,01), avec set.seed(3). Renvoie, dans l’ordre, le nombre de tests significatifs à 5 % (1) sans correction, (2) avec la correction de Bonferroni, (3) avec la correction de Benjamini-Hochberg (p.adjust).

AstuceIndice 1 · par où commencer

p.adjust(p, method = ...) renvoie les p-values corrigées ; on les compare à 0,05.

AstuceIndice 2 · la démarche

Résultat attendu : 3, 2, 2.

Raisonnement.

  1. Sans correction, 18 tests à 5 % produisent des faux positifs.
  2. Bonferroni multiplie les p-values par 18 : très prudent.
  3. BH contrôle la part de fausses découvertes : plus puissant quand beaucoup de tests sont vrais.

Lecture économique. Quand une étude teste de nombreux critères (sous-groupes, résultats secondaires), seuls les résultats qui survivent à la correction sont fiables : c’est la logique de la pré-inscription des analyses dans les essais randomisés.

set.seed(3) p <- c(runif(15), 0.0004, 0.002, 0.01) c(brut = sum(p < 0.05), bonferroni = sum(p.adjust(p, method = "bonferroni") < 0.05), bh = sum(p.adjust(p, method = "BH") < 0.05)) 
set.seed(3)
p <- c(runif(15), 0.0004, 0.002, 0.01)
c(brut = sum(p < 0.05),
  bonferroni = sum(p.adjust(p, method = "bonferroni") < 0.05),
  bh = sum(p.adjust(p, method = "BH") < 0.05))

Pièges fréquents.

  • Corriger après avoir choisi le meilleur test.
  • Confondre contrôle de l’erreur par famille (Bonferroni) et du taux de fausses découvertes (BH).

Pour aller plus loin. Change runif(15) en runif(150) : l’écart entre « brut » et « corrigé » s’agrandit.

Le p-hacking par simulation

Marche 4 sur 4 · Autonome

Un chercheur teste 20 hypothèses toutes fausses (aucun effet) à 5 % et publie s’il en trouve au moins une de significative. Simule 2 000 chercheurs (set.seed(4)), chacun avec 20 p-values uniformes (runif(20)), et renvoie un vecteur : (1) la part qui trouve au moins un résultat « significatif », (2) la valeur théorique 1 - 0.95^20.

AstuceIndice 1 · par où commencer

Sous H0, une p-value suit une loi uniforme sur [0, 1].

AstuceIndice 2 · la démarche

Probabilité d’au moins un succès sur 20 essais indépendants : 1 moins la probabilité de n’en avoir aucun.

Raisonnement.

  1. Sous H0, p ~ U(0, 1).
  2. any(...) vaut TRUE si au moins une p-value est inférieure à 0,05.
  3. La simulation (≈ 0,65) rejoint la théorie (0,64) : deux « chercheurs » sur trois publient un faux effet.

Lecture économique. C’est le mécanisme de la « crise de la reproductibilité » : explorer de nombreuses spécifications puis ne rapporter que la significative produit des résultats faux avec une grande probabilité.

set.seed(4) au_moins_un <- replicate(2000, any(runif(20) < 0.05)) c(simule = mean(au_moins_un), theorique = 1 - 0.95^20) 
set.seed(4)
au_moins_un <- replicate(2000, any(runif(20) < 0.05))
c(simule = mean(au_moins_un), theorique = 1 - 0.95^20)

Pièges fréquents.

  • Croire que 5 % de risque par test donne 5 % de risque global.
  • Oublier que les tests ne sont pas toujours indépendants.

Pour aller plus loin. Fais varier le nombre de tests (5, 50) et trace le risque global.

Économétrie avancée : effets fixes, différence de différences, instruments

Effets fixes : l’estimateur intra

Marche 1 sur 3 · Avancé

Données de panel simulées (50 individus, 5 périodes, set.seed(1)) : un effet individuel a corrèle avec x (x = 0.8*a + bruit) et y = 2*x + a + bruit. La vraie pente est 2. Renvoie c(pente MCO sur les niveaux, pente intra), la seconde étant obtenue après avoir retiré la moyenne de chaque individu (ave) à x et à y.

AstuceIndice 1 · par où commencer

ave(x, id) calcule la moyenne de x pour chaque individu ; on la retranche.

AstuceIndice 2 · la démarche

Résultat attendu : environ 2,80 (MCO) puis 2,18 (intra), la vraie valeur étant 2.

Raisonnement.

  1. L’effet individuel a est omis et corrèle avec x : les MCO sont biaisés (≈ 2,8).
  2. Retirer la moyenne par individu élimine a.
  3. L’estimateur intra se rapproche de 2 (≈ 2,2).

Lecture économique. Les effets fixes permettent de contrôler les caractéristiques inobservées constantes dans le temps (talent, institutions, culture) ; au prix de ne plus identifier l’effet de variables qui ne varient pas dans le temps.

set.seed(1); N <- 50; T <- 5; id <- rep(1:N, each = T) a <- rnorm(N, 0, 2)[id]; x <- 0.8 * a + rnorm(N * T); y <- 2 * x + a + rnorm(N * T) xd <- x - ave(x, id) yd <- y - ave(y, id) unname(c(coef(lm(y ~ x))[2], coef(lm(yd ~ xd))[2])) 
set.seed(1); N <- 50; T <- 5; id <- rep(1:N, each = T)
a <- rnorm(N, 0, 2)[id]; x <- 0.8 * a + rnorm(N * T); y <- 2 * x + a + rnorm(N * T)
xd <- x - ave(x, id)
yd <- y - ave(y, id)
unname(c(coef(lm(y ~ x))[2], coef(lm(yd ~ xd))[2]))

Pièges fréquents.

  • Oublier que les effets fixes ne traitent que l’hétérogénéité constante dans le temps.
  • Interpréter l’écart à la vraie valeur comme une erreur de code : il reflète le bruit d’échantillonnage.

Pour aller plus loin. Augmente N à 500 : la pente intra se rapproche de 2.

Différence de différences

Marche 2 sur 3 · Avancé

Simulation (set.seed(2), 400 observations) : un groupe traité (tr) et un groupe témoin, observés avant et après (po). Le vrai effet du traitement est 2. Calcule l’estimateur de différence de différences : (moyenne traités après − moyenne traités avant) − (moyenne témoins après − moyenne témoins avant).

AstuceIndice 1 · par où commencer

m est une matrice : lignes = groupe (0, 1), colonnes = période (0, 1).

AstuceIndice 2 · la démarche

Résultat attendu : environ 2,09.

Raisonnement.

  1. La première différence (traités) mélange l’effet du traitement et la tendance commune.
  2. La seconde (témoins) mesure la tendance commune.
  3. Leur différence isole l’effet, sous l’hypothèse de tendances parallèles.

Lecture économique. La différence de différences est l’outil central de l’évaluation des politiques (salaire minimum, réformes fiscales). Sa validité repose sur l’hypothèse de tendances parallèles, que l’on teste sur les périodes antérieures.

set.seed(2); n <- 400 tr <- rep(0:1, each = n / 2); po <- rep(c(0, 1), n / 2) y <- 1 + 0.5 * tr + 0.8 * po + 2 * tr * po + rnorm(n) m <- tapply(y, list(tr, po), mean) (m["1", "1"] - m["1", "0"]) - (m["0", "1"] - m["0", "0"]) 
set.seed(2); n <- 400
tr <- rep(0:1, each = n / 2); po <- rep(c(0, 1), n / 2)
y <- 1 + 0.5 * tr + 0.8 * po + 2 * tr * po + rnorm(n)
m <- tapply(y, list(tr, po), mean)
(m["1", "1"] - m["1", "0"]) - (m["0", "1"] - m["0", "0"])

Pièges fréquents.

  • Comparer uniquement avant/après sans groupe témoin.
  • Oublier l’hypothèse de tendances parallèles.

Pour aller plus loin. Vérifie le même résultat avec coef(lm(y ~ tr * po))["tr:po"].

Variable instrumentale et instrument faible

Marche 3 sur 3 · Autonome

Simulation (set.seed(5), 1 000 répétitions de 500 observations) : x est endogène (corrélé à l’erreur u) et l’instrument z est faible (x = 0.05*z + 0.8*u + bruit). La vraie pente de y sur x est 1. Dans chaque répétition, calcule la pente MCO cov(x,y)/var(x) et l’estimateur de Wald cov(z,y)/cov(z,x). Renvoie les médianes des deux estimateurs.

AstuceIndice 1 · par où commencer

Le ratio de Wald divise la covariance (instrument, résultat) par la covariance (instrument, régresseur).

AstuceIndice 2 · la démarche

apply(r, 1, median) calcule la médiane de chaque ligne (chaque estimateur).

Raisonnement.

  1. MCO est biaisé par l’endogénéité : médiane ≈ 1,80 pour une vraie valeur de 1.
  2. IV est centré près de la vraie valeur (≈ 1,21) mais très dispersé.
  3. Un instrument faible rend l’estimateur imprécis : vérifier la statistique F du premier étage.

Lecture économique. Les instruments faibles sont le piège classique de l’économétrie appliquée : l’estimateur IV peut être plus trompeur que les MCO. D’où l’exigence d’une statistique F du premier étage supérieure à 10 (règle empirique).

set.seed(5) sim <- function() { n <- 500; z <- rnorm(n); u <- rnorm(n) x <- 0.05 * z + 0.8 * u + rnorm(n, 0, 0.6); y <- 1 * x + u + rnorm(n) c(mco = cov(x, y) / var(x), iv = cov(z, y) / cov(z, x)) } r <- replicate(1000, sim()) unname(apply(r, 1, median)) 
set.seed(5)
sim <- function() {
  n <- 500; z <- rnorm(n); u <- rnorm(n)
  x <- 0.05 * z + 0.8 * u + rnorm(n, 0, 0.6); y <- 1 * x + u + rnorm(n)
  c(mco = cov(x, y) / var(x), iv = cov(z, y) / cov(z, x))
}
r <- replicate(1000, sim())
unname(apply(r, 1, median))

Pièges fréquents.

  • Utiliser un instrument sans tester sa force.
  • Oublier que l’instrument doit aussi être exogène (non corrélé à u).

Pour aller plus loin. Mesure aussi l’étendue interquartile de l’IV (IQR) : elle illustre l’imprécision.

Micro avancée : entrée et bien-être

Cournot avec libre entrée

Marche 1 sur 2 · Avancé

Demande inverse P = 100 - Q, coût marginal 10, coût fixe 200. À l’équilibre de Cournot à N firmes, chaque firme produit 90/(N+1). Avec libre entrée, les firmes entrent tant que le profit est positif. Renvoie le plus grand N pour lequel le profit net du coût fixe est positif ou nul.

AstuceIndice 1 · par où commencer

Il faut soustraire le coût fixe F au profit brut.

AstuceIndice 2 · la démarche

Le profit net est décroissant en N ; N[profit >= 0] liste les N viables.

Raisonnement.

  1. Profit brut d’une firme : (P − cmg) q = (90/(N+1))².
  2. On soustrait F = 200.
  3. Le plus grand N avec profit ≥ 0 est 5.

Lecture économique. Plus le coût fixe est élevé, moins le marché peut accueillir de firmes : les coûts fixes (réseaux, infrastructures) expliquent la concentration de nombreux secteurs sans qu’il y ait de collusion.

P0 <- 100; cmg <- 10; F <- 200; a <- P0 - cmg # demande P = 100 - Q ; coût marginal 10 ; coût fixe 200 N <- 1:10; q <- a / (N + 1); Q <- N * q; P <- P0 - Q; profit <- (P - cmg) * q - F max(N[profit >= 0]) 
P0 <- 100; cmg <- 10; F <- 200; a <- P0 - cmg      # demande P = 100 - Q ; coût marginal 10 ; coût fixe 200
N <- 1:10; q <- a / (N + 1); Q <- N * q; P <- P0 - Q; profit <- (P - cmg) * q - F
max(N[profit >= 0])

Pièges fréquents.

  • Oublier de soustraire F.
  • Confondre q (production par firme) et Q (production totale).

Pour aller plus loin. Augmente F à 500 : combien de firmes restent ?

Trop d’entrée : optimum social

Marche 2 sur 2 · Autonome

Reprends le marché précédent. Le surplus total est Q²/2 (surplus des consommateurs) plus les profits nets de tous les entrants (N × profit). Renvoie le nombre de firmes N qui maximise le surplus total : est-il inférieur au nombre d’entrants libres ?

AstuceIndice 1 · par où commencer

which.max(W) renvoie la position du maximum ; N[...] donne le nombre de firmes correspondant.

AstuceIndice 2 · la démarche

Résultat attendu : 2, contre 5 avec libre entrée.

Raisonnement.

  1. Le surplus des consommateurs augmente avec Q, donc avec N.
  2. Mais chaque entrant paie un coût fixe de 200.
  3. L’optimum social (N = 2) est inférieur à l’équilibre libre (N = 5) : il y a excès d’entrée.

Lecture économique. Les firmes qui entrent ne tiennent pas compte du fait qu’elles volent des parts de marché aux autres (effet de « vol d’activité ») : le résultat est un excès d’entrée par rapport à l’optimum, argument classique pour la régulation de l’entrée dans les industries à coûts fixes élevés.

P0 <- 100; cmg <- 10; F <- 200; a <- P0 - cmg # demande P = 100 - Q ; coût marginal 10 ; coût fixe 200 N <- 1:10; q <- a / (N + 1); Q <- N * q; P <- P0 - Q; profit <- (P - cmg) * q - F W <- Q^2 / 2 + N * profit N[which.max(W)] 
P0 <- 100; cmg <- 10; F <- 200; a <- P0 - cmg      # demande P = 100 - Q ; coût marginal 10 ; coût fixe 200
N <- 1:10; q <- a / (N + 1); Q <- N * q; P <- P0 - Q; profit <- (P - cmg) * q - F
W <- Q^2 / 2 + N * profit
N[which.max(W)]

Pièges fréquents.

  • Maximiser le profit au lieu du surplus total.
  • Oublier de compter les coûts fixes de chaque entrant.

Pour aller plus loin. Trace W en fonction de N pour visualiser le maximum.
