R : les bases et les graphiques

Vecteurs, tableaux, fonctions, puis graphiques de base pas à pas

Deux pistes progressives, avec indices et corrigés. R : bases couvre les vecteurs, les tableaux de données et les fonctions ; R : graphiques part de plot() et va jusqu’aux figures à plusieurs panneaux. Les graphiques se vérifient par ce que R renvoie (limites des axes avec par("usr"), objets renvoyés par hist(), boxplot(), barplot()), pas par l’œil. Les énoncés changent chaque jour.

Astuce

Une marche te paraît trop haute ? Fais d’abord les échauffements : un seul trou, des données réelles, 2 à 5 minutes. Le bouton « ⚡ Plus court » de la page Aujourd’hui te propose aussi un exercice court. Pour varier les gestes (tableaux, débogage, lecture de sorties et de graphiques, rédaction) : l’Atelier ; pour aller plus loin : le niveau avancé.

rng = {
  // Générateur pseudo-aléatoire reproductible : graine = jour + id d'exercice + salt.
  // (Source unique : scripts/test_exercices.R évalue cette même cellule avec Node.)
  const today = new Date().toISOString().slice(0, 10);
  const hash = (s) => {
    let h = 1779033703 ^ s.length;
    for (let i = 0; i < s.length; i++) { h = Math.imul(h ^ s.charCodeAt(i), 3432918353); h = (h << 13) | (h >>> 19); }
    return h >>> 0;
  };
  const mulberry32 = (a) => () => {
    a |= 0; a = (a + 0x6d2b79f5) | 0;
    let t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
  return (id, salt = 0, day = today) => {
    const u = mulberry32(hash(`${day}|${id}|${salt}`));
    const int = (a, b) => a + Math.floor(u() * (b - a + 1));
    const pick = (arr) => arr[Math.floor(u() * arr.length)];
    const normal = () => Math.sqrt(-2 * Math.log(1 - u())) * Math.cos(2 * Math.PI * u());
    return { u, int, pick, normal };
  };
}

Vecteurs : indexer, filtrer, compter

Marche 1 sur 3 · Guidé

rb0 = { const g = rng("r-base-0", salt); return { seed: g.int(1, 9999), s: g.int(25, 50) }; }

Un vecteur de 15 valeurs est tiré avec la graine . Avec le seuil s = , compte les valeurs strictement supérieures à s, calcule leur moyenne, trouve la position de la plus grande valeur, puis plafonne le vecteur à s (toute valeur au-dessus de s devient s) et renvoie la somme du vecteur plafonné.

AstuceIndice 1 · par où commencer

Une comparaison comme x > s renvoie un vecteur de TRUE/FALSE. On peut le sommer (TRUE vaut 1) pour compter, ou l’utiliser dans des crochets pour filtrer.

AstuceIndice 2 · la formule

n_sup = sum(x > s) ; moy_sup = mean(x[x > s]) ; pos_max = which.max(x) ; plafond = ifelse(x > s, s, x) (ou pmin(x, s)).

Raisonnement.

  1. x > s est vectorisé : il compare chaque élément à s et renvoie un vecteur logique de même longueur.
  2. sum() d’un logique compte les TRUE ; x[x > s] extrait les éléments pour lesquels la condition est vraie.
  3. which.max(x) renvoie la position du maximum, max(x) sa valeur : ne pas confondre.
  4. ifelse(test, oui, non) applique un choix élément par élément. pmin(x, s) fait la même chose pour un plafond.
set.seed(rb0$seed) x <- round(runif(15, 10, 100)) s <- rb0$s n_sup <- sum(x > s) moy_sup <- mean(x[x > s]) pos_max <- which.max(x) plafond <- ifelse(x > s, s, x) c(n_sup = n_sup, moy_sup = moy_sup, pos_max = pos_max, somme_plafond = sum(plafond)) 
set.seed(rb0$seed)

s <- rb0$s
n_sup   <- sum(x > s)
moy_sup <- mean(x[x > s])
pos_max <- which.max(x)
plafond <- ifelse(x > s, s, x)
c(n_sup = n_sup, moy_sup = moy_sup, pos_max = pos_max, somme_plafond = sum(plafond))

Pièges fréquents.

  • x[x > s] sans la comparaison entre crochets, ou x[> s] : erreur de syntaxe.
  • max(x) à la place de which.max(x) : la valeur n’est pas la position.
  • if (x > s) au lieu de ifelse(x > s, ...) : if n’accepte qu’une seule condition, pas un vecteur.

Pour aller plus loin. Écris x[order(x, decreasing = TRUE)][1:3] : à quoi sert chaque partie ? Compare avec sort(x, decreasing = TRUE)[1:3].

Tableaux de données : sélectionner, résumer, comparer

Marche 2 sur 3 · À compléter

rb1 = { const g = rng("r-base-1", salt); return { seed: g.int(1, 9999), ecart: g.int(10, 40) * 10 }; }

Un tableau de 80 individus (âge, sexe, revenu) est simulé avec la graine . Sélectionne les femmes de 30 ans ou plus, donne leur nombre et leur revenu moyen, calcule l’écart de revenu moyen hommes − femmes (tous âges), et donne l’âge de la personne au revenu le plus élevé.

AstuceIndice 1 · par où commencer

Un data frame s’indexe df[lignes, colonnes]. Pour filtrer des lignes, mets une condition logique dans le premier emplacement et laisse le second vide : df[condition, ]. Combine les conditions avec &.

AstuceIndice 2 · la formule

cible <- df[df$sexe == "F" & df$age >= 30, ] ; moy_sexe <- tapply(df$revenu, df$sexe, mean) ; age_plus_riche = df$age[which.max(df$revenu)].

Raisonnement.

  1. La virgule dans df[lignes, ] est essentielle : sans elle, R sélectionne des colonnes.
  2. On combine deux conditions avec & (et), pas && : & agit élément par élément, && ne regarde que le premier.
  3. tapply(valeur, groupe, fonction) résume un vecteur par modalité d’un facteur et renvoie un vecteur nommé : on extrait ensuite avec [["H"]].
  4. which.max() donne la position de la ligne la mieux payée ; on l’utilise pour lire l’âge correspondant dans la même ligne.
set.seed(rb1$seed) df <- data.frame(age = sample(18:65, 80, replace = TRUE), sexe = sample(c("F", "H"), 80, replace = TRUE)) df$revenu <- round(1200 + 25 * df$age + ifelse(df$sexe == "H", rb1$ecart, 0) + rnorm(80, 0, 150)) cible <- df[df$sexe == "F" & df$age >= 30, ] moy_sexe <- tapply(df$revenu, df$sexe, mean) c(n_cible = nrow(cible), moy_cible = mean(cible$revenu), ecart_HF = moy_sexe[["H"]] - moy_sexe[["F"]], age_plus_riche = df$age[which.max(df$revenu)]) 
set.seed(rb1$seed)

df$revenu <- round(1200 + 25 * df$age + ifelse(df$sexe == "H", rb1$ecart, 0) + rnorm(80, 0, 150))
cible    <- df[df$sexe == "F" & df$age >= 30, ]

Pièges fréquents.

  • Oublier la virgule : df[df$sexe == "F", ] filtre les lignes ; df[df$sexe == "F"] déclenche une erreur.
  • Utiliser = au lieu de == dans une condition : = affecte, == compare.
  • && au lieu de & dans un filtre de lignes.

Pour aller plus loin. Refais le résumé par groupe avec aggregate(revenu ~ sexe, data = df, FUN = mean) : quelle différence de format pour le résultat ?

Écrire une fonction et l’appliquer à une liste

Marche 3 sur 3 · Autonome

rb2 = { const g = rng("r-base-2", salt); return { seed: g.int(1, 9999), k: g.int(1, 3) }; }

On simule 5 séries de prix (graine , facteur de bruit ). Écris une fonction volatilite(x) qui renvoie l’écart-type des variations relatives successives (diff(x) divisé par les valeurs précédentes), applique-la aux 5 séries avec vapply, et renvoie le numéro de la série la plus volatile, la volatilité maximale et la volatilité minimale.

AstuceIndice 1 · par où commencer

Une fonction se définit nom <- function(argument) { ... } et renvoie sa dernière expression. Ici, calcule d’abord les variations relatives de x (différences successives rapportées au niveau précédent), puis leur écart-type.

AstuceIndice 2 · la formule

volatilite <- function(x) sd(diff(x) / x[-length(x)]) ; x[-length(x)] retire le dernier élément, donc aligne chaque variation avec la valeur de départ. vapply(liste, f, numeric(1)) applique f à chaque élément et exige un nombre en retour.

Raisonnement.

  1. diff(x) renvoie \(x_{t+1} - x_t\) (un élément de moins que x) ; on divise par x[-length(x)], les valeurs de départ, pour obtenir des variations relatives.
  2. Une fonction renvoie la valeur de sa dernière expression : pas besoin de return().
  3. vapply(series, volatilite, numeric(1)) est une version sûre de sapply : elle échoue clairement si la fonction ne renvoie pas un nombre.
  4. which.max(vol) donne l’indice de la série la plus volatile : les séries ont été construites avec un bruit croissant, la 5e devrait gagner en moyenne.
set.seed(rb2$seed) series <- lapply(1:5, function(i) round(100 * cumprod(1 + rnorm(20, 0.01, 0.005 * i * rb2$k)), 2)) volatilite <- function(x) sd(diff(x) / x[-length(x)]) vol <- vapply(series, volatilite, numeric(1)) c(plus_volatile = which.max(vol), vol_max = max(vol), vol_min = min(vol)) 
set.seed(rb2$seed)
series <- lapply(1:5, function(i) round(100 * cumprod(1 + rnorm(20, 0.01, 0.005 * i * rb2$k)), 2))
volatilite <- function(x) sd(diff(x) / x[-length(x)])
vol <- vapply(series, volatilite, numeric(1))
c(plus_volatile = which.max(vol), vol_max = max(vol), vol_min = min(vol))

Pièges fréquents.

  • Diviser diff(x) par x entier : les longueurs diffèrent (recyclage silencieux ou avertissement).
  • Calculer sd(diff(x)) sans rapporter au niveau : la volatilité absolue dépend de l’échelle de la série.
  • Utiliser sapply partout : un résultat de mauvais type passe inaperçu, alors que vapply l’attrape.

Pour aller plus loin. Ajoute un argument fenetre = 5 pour calculer la volatilité sur les fenetre dernières observations seulement, avec une valeur par défaut.

Premier graphique : une série temporelle propre

Marche 1 sur 4 · Guidé

rg0 = { const g = rng("r-graph-0", salt); return { seed: g.int(1, 9999), g: g.int(1, 4) }; }

Trace l’évolution du PIB (indice) entre 2010 et 2024 avec la fonction plot() : lignes et points, points pleins, couleur steelblue, un axe vertical qui commence à 0, des titres d’axes et un titre. Puis lis les limites réelles des axes avec par("usr") : c’est ainsi qu’on vérifie un graphique sans le regarder.

AstuceIndice 1 · par où commencer

plot(x, y, ...) accepte des arguments nommés qui règlent l’apparence : type (“p” points, “l” lignes, “b” les deux), pch (symbole), col, xlab, ylab, main, et ylim = c(min, max) pour fixer l’étendue verticale.

AstuceIndice 2 · la formule

plot(annee, pib, type = "b", pch = 19, col = "steelblue", ylim = c(0, max(pib)), xlab = "Année", ylab = "PIB (indice)", main = "Évolution du PIB").

Raisonnement.

  1. plot(x, y) dessine un nuage de points ; l’argument type change la représentation : "b" relie les points par des segments.
  2. Par défaut, R choisit l’étendue de l’axe vertical à partir des données : une série proche de 100 serait tronquée loin de 0. Pour ne pas exagérer les variations visuelles, on impose ylim = c(0, max(pib)).
  3. R ajoute toujours 4 % de marge de chaque côté : par("usr") renvoie donc ylim élargi de 4 %.
  4. Le titre et les libellés des axes font partie du graphique, pas de la légende : un graphique sans unités ni titre est difficile à lire seul.
set.seed(rg0$seed) annee <- 2010:2024 pib <- round(100 * cumprod(1 + rnorm(15, rg0$g / 100, 0.01)), 1) plot(annee, pib, type = "b", pch = 19, col = "steelblue", ylim = c(0, max(pib)), xlab = "Année", ylab = "PIB (indice)", main = "Évolution du PIB") par("usr") 
set.seed(rg0$seed)
annee <- 2010:2024
pib <- round(100 * cumprod(1 + rnorm(15, rg0$g / 100, 0.01)), 1)
plot(annee, pib, type = "b", pch = 19, col = "steelblue", ylim = c(0, max(pib)),
     xlab = "Année", ylab = "PIB (indice)", main = "Évolution du PIB")
par("usr")

Pièges fréquents.

  • Écrire plot(pib ~ annee) puis oublier ylim : le graphique s’ouvre sur un axe tronqué, qui exagère la croissance.
  • Mettre col = steelblue sans guillemets : R cherche un objet nommé steelblue.
  • Confondre type = "l" (ligne seule) et type = "b" (ligne et points) ; "o" superpose les points à la ligne.

Pour aller plus loin. Essaie type = "s" (escalier) et col = adjustcolor("steelblue", 0.5) (transparence). Pour la liste des couleurs, colors() et hcl.colors(5).

Histogramme en densité et courbe de densité

Marche 2 sur 4 · À compléter

rg1 = { const g = rng("r-graph-1", salt); return { seed: g.int(1, 9999), L: g.pick([0.5, 1]) }; }

Représente la distribution de 500 revenus (milliers d’euros, graine ) par un histogramme en densité (l’aire totale vaut 1) avec des classes de largeur , de 0 jusqu’à la première borne au-dessus du maximum. Superpose la courbe de densité estimée. Renvoie le nombre de classes, l’aire totale de l’histogramme et la limite haute de l’axe vertical.

AstuceIndice 1 · par où commencer

hist(x, breaks = ...) accepte un vecteur de bornes pour des classes de largeur choisie ; freq = FALSE affiche des densités au lieu d’effectifs. La borne haute doit couvrir le maximum : arrondis max(x) / L à l’entier supérieur.

AstuceIndice 2 · la formule

h <- hist(x, breaks = seq(0, ceiling(max(x) / L) * L, by = L), freq = FALSE, col = "grey85", main = "Revenus", xlab = "Milliers d'euros") ; lines(density(x), col = "red", lwd = 2).

Raisonnement.

  1. Avec breaks = seq(0, borne, by = L), chaque classe a la même largeur ; ceiling(max(x) / L) * L donne la première borne au-dessus du maximum.
  2. freq = FALSE normalise : la hauteur d’une barre est l’effectif divisé par (n × largeur), donc l’aire totale vaut 1. C’est ce qui permet de superposer une densité estimée.
  3. lines() ajoute une courbe au graphique courant, sans en créer un nouveau ; density(x) fournit les coordonnées.
  4. L’objet renvoyé par hist() contient counts, density et breaks : utile pour vérifier ou réutiliser le calcul.
set.seed(rg1$seed) x <- rlnorm(500, 0.5, 0.6) L <- rg1$L h <- hist(x, breaks = seq(0, ceiling(max(x) / L) * L, by = L), freq = FALSE, col = "grey85", main = "Distribution des revenus", xlab = "Milliers d'euros") lines(density(x), col = "red", lwd = 2) c(classes = length(h$counts), aire = sum(h$density * diff(h$breaks)), ymax_axe = par("usr")[4]) 
set.seed(rg1$seed)
x <- rlnorm(500, 0.5, 0.6)
L <- rg1$L
h <- hist(x, breaks = seq(0, ceiling(max(x) / L) * L, by = L), freq = FALSE,

lines(density(x), col = "red", lwd = 2)
c(classes = length(h$counts), aire = sum(h$density * diff(h$breaks)), ymax_axe = par("usr")[4])

Pièges fréquents.

  • Oublier freq = FALSE : la courbe de densité (valeurs autour de 0,3) serait écrasée par des barres de hauteur 100.
  • Laisser R choisir breaks quand on compare deux histogrammes : les classes diffèrent, la comparaison est trompeuse.
  • Appeler plot(density(x)) après hist() : cela ouvre un nouveau graphique au lieu d’ajouter la courbe.

Pour aller plus loin. Essaie breaks = "FD" (règle de Freedman-Diaconis) ou "Sturges" : combien de classes obtiens-tu ? Pourquoi les résultats diffèrent-ils ?

Comparer des groupes : boîtes à moustaches et barres

Marche 3 sur 4 · À compléter

rg2 = { const g = rng("r-graph-2", salt); return { seed: g.int(1, 9999), b: g.int(10, 14) }; }

Un échantillon de 200 salaires horaires (graine ) selon le diplôme (Bac, Licence, Master). Trace les boîtes à moustaches du salaire par diplôme avec la notation formule salaire ~ diplome, puis un diagramme en barres des moyennes par diplôme. Renvoie les trois médianes (lues dans l’objet renvoyé par boxplot), le nombre de valeurs atypiques et le nombre de barres.

AstuceIndice 1 · par où commencer

boxplot() accepte une formule y ~ groupe avec l’argument data, ou deux vecteurs séparés (boxplot(salaire ~ diplome) fonctionne directement car les deux sont dans l’environnement). barplot() prend un vecteur de hauteurs, avec names.arg ou un vecteur nommé.

AstuceIndice 2 · la formule

b <- boxplot(salaire ~ diplome, col = "grey85", ylab = "Salaire horaire (euros)") ; bp <- barplot(moy, ylab = "Salaire moyen (euros)", ylim = c(0, max(moy) * 1.1)). La ligne 3 de b$stats contient les médianes.

Raisonnement.

  1. La formule y ~ g se lit « y expliqué par g » : boxplot trace une boîte par modalité de g. Elle fonctionne avec presque toutes les fonctions graphiques et statistiques de R (plot, t.test, lm, aggregate).
  2. boxplot() renvoie ses statistiques invisiblement : b$stats (5 lignes : minimum, Q1, médiane, Q3, maximum hors atypiques), b$out (les valeurs atypiques), b$n.
  3. Une boîte résume la distribution (médiane, quartiles, valeurs atypiques) ; une barre de moyenne cache la dispersion. Pour des comparaisons de groupes, la boîte est plus informative.
  4. barplot() renvoie les abscisses des barres : on peut s’en servir pour ajouter du texte ou des barres d’erreur au bon endroit.
set.seed(rg2$seed) n <- 200 diplome <- factor(sample(c("Bac", "Licence", "Master"), n, replace = TRUE, prob = c(0.5, 0.3, 0.2)), levels = c("Bac", "Licence", "Master")) salaire <- round(c(Bac = rg2$b, Licence = rg2$b + 3, Master = rg2$b + 7)[diplome] * exp(rnorm(n, 0, 0.3)), 2) b <- boxplot(salaire ~ diplome, col = "grey85", ylab = "Salaire horaire (euros)") moy <- tapply(salaire, diplome, mean) bp <- barplot(moy, ylab = "Salaire moyen (euros)", ylim = c(0, max(moy) * 1.1)) c(b$stats[3, ], n_atypiques = length(b$out), barres = length(bp))

Pièges fréquents.

  • Oublier de donner des niveaux ordonnés au facteur : sinon R trie les modalités par ordre alphabétique (Bac, Licence, Master ici par chance).
  • Tronquer l’axe vertical d’un barplot : la hauteur des barres est interprétée comme une quantité, il faut que l’axe parte de 0.

Pour aller plus loin. Ajoute les points individuels par-dessus : stripchart(salaire ~ diplome, vertical = TRUE, method = "jitter", add = TRUE, pch = 16, col = rgb(0, 0, 0, 0.25)).

Plusieurs graphiques : droite de régression et diagnostic des résidus

Marche 4 sur 4 · Autonome

rg3 = { const g = rng("r-graph-3", salt); return { seed: g.int(1, 9999), b: g.int(5, 20) / 10 }; }

Deux graphiques côte à côte (une ligne, deux colonnes) pour 80 observations (graine ) : à gauche le nuage de points de y contre x avec la droite des moindres carrés et une légende ; à droite le diagramme quantile-quantile des résidus avec sa droite de référence. Restaure ensuite la disposition initiale. Renvoie la pente, l’ordonnée à l’origine et la disposition (lignes, colonnes) lue avant restauration.

AstuceIndice 1 · par où commencer

par(mfrow = c(lignes, colonnes)) découpe la fenêtre en panneaux, remplis ligne par ligne. par() renvoie l’ancienne valeur : la garder dans op permet de restaurer avec par(op). abline() accepte directement un objet lm pour tracer sa droite.

AstuceIndice 2 · la formule

par(mfrow = c(1, 2)) ; fit <- lm(y ~ x) ; abline(fit, col = "red", lwd = 2) ; legend("topleft", legend = "Droite MCO", ...). qqline() trace la droite de référence d’un qqnorm.

Raisonnement.

  1. par(mfrow = c(1, 2)) modifie un réglage global de la fenêtre graphique ; sans restauration, tous les graphiques suivants garderaient cette disposition.
  2. op <- par(...) mémorise les anciennes valeurs, et par(op) les remet : le réflexe à adopter dans toute fonction qui change par().
  3. abline(fit) utilise les coefficients du modèle : plus fiable que de recopier a et b à la main. legend() se place par mot-clé de position ("topleft") ou par coordonnées.
  4. qqnorm(resid(fit)) compare les quantiles des résidus à ceux d’une loi normale : si les points suivent la droite de qqline(), l’hypothèse de normalité est plausible. C’est un diagnostic visuel, à compléter par l’examen d’autres hypothèses.
set.seed(rg3$seed) x <- rnorm(80, 10, 2); y <- 3 + rg3$b * x + rnorm(80, 0, 2) op <- par(mfrow = c(1, 2)) m <- par("mfrow") plot(x, y, pch = 19, col = "grey40", main = "Nuage et droite MCO") fit <- lm(y ~ x) abline(fit, col = "red", lwd = 2) legend("topleft", legend = "Droite MCO", col = "red", lwd = 2, bty = "n") qqnorm(resid(fit)); qqline(resid(fit)) par(op) c(pente = coef(fit)[[2]], ordonnee = coef(fit)[[1]], lignes = m[1], colonnes = m[2])

Pièges fréquents.

  • Oublier par(op) : les graphiques suivants restent coupés en deux panneaux.
  • c(2, 1) au lieu de c(1, 2) : deux lignes, une colonne, soit l’inverse de la disposition voulue.
  • Appeler plot() à la place de abline() pour ajouter la droite : cela ouvre un nouveau panneau au lieu de compléter celui-ci.

Pour aller plus loin. Remplace par(mfrow = ...) par layout(matrix(c(1, 1, 2, 3), 2, byrow = TRUE)) pour obtenir un grand panneau en haut et deux petits en bas.

Bonnes pratiques. (1) L’axe d’un diagramme en barres part de 0. (2) Chaque axe a un libellé avec son unité. (3) Ne distingue pas les groupes par la seule couleur si le graphique sera imprimé en noir et blanc : ajoute pch ou lty. (4) Préfère une boîte à moustaches ou les points individuels à une simple barre de moyenne pour comparer des groupes. (5) Fixe set.seed() pour qu’un graphique simulé soit reproductible.

Exporter un graphique et passer à ggplot2 (sur ton ordinateur)

Dans le navigateur (webR), les graphiques s’affichent dans la page. Sur ton ordinateur (RStudio), tu les enregistres ainsi, en ouvrant un fichier, en dessinant, puis en le fermant :

png("figure1.png", width = 1600, height = 1000, res = 200)   # ou pdf("figure1.pdf", width = 8, height = 5)
plot(annee, pib, type = "b", pch = 19, col = "steelblue", ylim = c(0, max(pib)))
dev.off()                                                    # indispensable : écrit le fichier

Le même graphique avec ggplot2 (à installer en local : install.packages("ggplot2")) :

library(ggplot2)
ggplot(data.frame(annee, pib), aes(annee, pib)) +
  geom_line(colour = "steelblue") + geom_point() +
  scale_y_continuous(limits = c(0, NA)) +
  labs(x = "Année", y = "PIB (indice)", title = "Évolution du PIB") +
  theme_minimal()
ggsave("figure1.png", width = 8, height = 5, dpi = 200)

La syntaxe de base (plot, hist, boxplot) est rapide pour explorer ; ggplot2 est plus économe pour des figures publiables avec plusieurs groupes. Les deux s’appuient sur les mêmes idées : données, axes, couleurs, légende.
