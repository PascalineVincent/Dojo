Concepts macro, identités et ordres de grandeur

Un an de dette : l’effet boule de neige

Marche 1 sur 3 · Guidé

dette0 = { const g = rng("con-dette-0", salt); return { d0: g.int(60, 120), r: g.pick([1, 2, 3, 4]), g: g.pick([0, 1, 2, 3]), pb: g.int(-3, 2) }; }

La dette publique représente % du PIB. Le taux d’intérêt nominal moyen est de %, la croissance nominale du PIB de % et le solde primaire de % du PIB (positif = excédent). Calcule la part de la variation du ratio due à l’écart entre le taux d’intérêt et la croissance (effet boule de neige), puis le ratio de l’année suivante.

AstuceIndice 1 · par où commencer

Pars de la récurrence \(d' = d\,(1+r)/(1+g) - pb\) et isole le terme qui dépend de l’écart \(r - g\) du reste.

AstuceIndice 2 · la formule

\((1+r)/(1+g) = 1 + (r-g)/(1+g)\), donc boule \(= d_0\,(r-g)/(1+g)\) et \(d_1 = d_0 + \text{boule} - pb\).

Raisonnement.

  1. En niveau, la dette grossit des intérêts : \(D' = (1+r)D - PB\). Le PIB grossit de \(g\) ; le ratio devient \(d' = \dfrac{1+r}{1+g}\,d - pb\).
  2. On sépare l’effet de l’écart \(r-g\) : comme \(\dfrac{1+r}{1+g} = 1 + \dfrac{r-g}{1+g}\), on obtient \(d' = d + \dfrac{r-g}{1+g}\,d - pb\).
  3. Le terme \(\dfrac{r-g}{1+g}\,d\) est l’effet boule de neige. Si \(r > g\), la dette gonfle même sans déficit primaire ; si \(r < g\), elle se dilue spontanément.
  4. Le solde primaire est en points de PIB : un excédent (\(pb > 0\)) se retranche directement du ratio.
d0 <- dette0$d0; r <- dette0$r / 100; g <- dette0$g / 100; pb <- dette0$pb boule <- d0 * (r - g) / (1 + g) # effet boule de neige d1 <- d0 + boule - pb # = d0 * (1 + r) / (1 + g) - pb c(boule = boule, d1 = d1) 
d0 <- dette0$d0; r <- dette0$r / 100; g <- dette0$g / 100; pb <- dette0$pb
boule <- d0 * (r - g) / (1 + g)       # effet boule de neige
d1 <- d0 + boule - pb                 # = d0 * (1 + r) / (1 + g) - pb
c(boule = boule, d1 = d1)

Pièges fréquents.

  • Garder \(r\) et \(g\) en pourcentage : le terme serait cent fois trop grand.
  • Oublier le dénominateur \(1+g\) : pour de faibles taux l’écart est minime, mais l’identité exacte l’inclut.
  • Inverser le signe du solde primaire : un excédent réduit la dette.

Pour aller plus loin. La marche suivante répète ce calcul sur dix ans.

Dynamique de la dette publique

Marche 2 sur 3 · À compléter

dette1 = { const g = rng("con-dette-1", salt); return { d0: g.int(60, 120), r: g.pick([1, 2, 3, 4]), g: g.pick([0, 1, 2, 3]), pb: g.int(-3, 2) }; }

La dette publique représente % du PIB. Le taux d’intérêt nominal moyen est de %, la croissance nominale du PIB de % et le solde primaire de % du PIB (positif = excédent). Simule 10 ans d’évolution du ratio dette/PIB avec la récurrence : d(t+1) = d(t) × (1 + r) / (1 + g) − pb.

AstuceIndice 1 · par où commencer

C’est un calcul récursif : la dette de l’année suivante dépend de celle de l’année en cours. Écris d’abord le passage de \(t\) à \(t+1\), puis répète-le dix fois avec une boucle.

AstuceIndice 2 · la formule

Le premier terme est l’effet « boule de neige » : si \(r > g\) il fait croître le ratio même sans nouveau déficit primaire. Le solde primaire est exprimé en points de PIB : il se retranche directement.

Raisonnement.

  1. En niveau, la dette s’accroît des intérêts et diminue de l’excédent primaire : \(D_{t+1} = (1+r)\,D_t - PB_t\).
  2. Le PIB nominal croît de \(g\) : \(Y_{t+1} = (1+g)\,Y_t\).
  3. En divisant, le ratio suit \(d_{t+1} = d_t\,\dfrac{1+r}{1+g} - pb\).
  4. Décomposition : \(d_{t+1} - d_t = \dfrac{r-g}{1+g}\,d_t - pb\) : un effet « boule de neige » moins le solde primaire.
  5. On itère dix fois avec une boucle : chaque ligne utilise la valeur de la ligne précédente (d[t]). À long terme le ratio se stabilise à \(d^* = \dfrac{(1+g)\,pb}{r-g}\) si \(r>g\) et \(pb>0\).
d0 <- dette1$d0; r <- dette1$r / 100; g <- dette1$g / 100; pb <- dette1$pb d <- numeric(11); d[1] <- d0 for (t in 1:10) d[t + 1] <- d[t] * (1 + r) / (1 + g) - pb c(d_final = d[11], variation = d[11] - d0) 
d0 <- dette1$d0; r <- dette1$r / 100; g <- dette1$g / 100; pb <- dette1$pb
d <- numeric(11); d[1] <- d0
for (t in 1:10) d[t + 1] <- d[t] * (1 + r) / (1 + g) - pb
c(d_final = d[11], variation = d[11] - d0)

Pièges fréquents.

  • Mettre \(r\) et \(g\) en pourcentage (2 au lieu de 0,02) : le gabarit les convertit déjà.
  • Écrire d0 au lieu de d[t] dans la boucle : la dette ne « s’accumule » plus.
  • Lire \(pb > 0\) comme un déficit : ici un solde primaire positif est un excédent, qui réduit la dette.

Pour aller plus loin. La marche suivante inverse la question : quel solde primaire maintient le ratio constant ?

Solde primaire stabilisant

Marche 3 sur 3 · Autonome

dette2 = { const g = rng("con-dette-2", salt); return { d0: g.int(60, 120), r: g.pick([1, 2, 3, 4]), g: g.pick([0, 1, 2, 3]) }; }

La dette représente % du PIB, avec un taux d’intérêt nominal de % et une croissance nominale de %. Écris la fonction pb_stab(d, r, g) qui donne le solde primaire (en points de PIB) maintenant le ratio constant, puis vérifie par simulation sur 10 ans.

AstuceIndice 1 · par où commencer

Un ratio stable signifie \(d_{t+1} = d_t\). Écris cette égalité dans la récurrence \(d_{t+1} = d_t\,(1+r)/(1+g) - pb\) et isole \(pb\).

AstuceIndice 2 · la formule

\(pb^* = d\left(\dfrac{1+r}{1+g} - 1\right) = d\,\dfrac{r-g}{1+g}\).

Raisonnement.

  1. On veut \(d_{t+1} = d_t = d\) : \(d\,\dfrac{1+r}{1+g} - pb = d\).
  2. D’où \(pb^* = d\left(\dfrac{1+r}{1+g} - 1\right) = d\,\dfrac{r-g}{1+g}\).
  3. Lecture : stabiliser le ratio coûte d’autant plus que la dette est élevée et que l’écart \(r-g\) est grand. Si \(r < g\), le solde primaire stabilisant est négatif : on peut supporter un déficit primaire sans que le ratio monte.
  4. La simulation confirme : avec \(pb^*\), le ratio reste exactement à \(d_0\) après dix ans.
  5. \(pb^*\) ne fait que stabiliser : pour réduire le ratio, il faut un solde primaire supérieur.
d0 <- dette2$d0; r <- dette2$r / 100; g <- dette2$g / 100 pb_stab <- function(d, r, g) d * (r - g) / (1 + g) # stabilisation : d_{t+1} = d_t pb <- pb_stab(d0, r, g) d <- d0; for (t in 1:10) d <- d * (1 + r) / (1 + g) - pb c(pb_stabilisant = pb, d_apres_10_ans = d) 
d0 <- dette2$d0; r <- dette2$r / 100; g <- dette2$g / 100
pb_stab <- function(d, r, g) d * (r - g) / (1 + g)     # stabilisation : d_{t+1} = d_t
pb <- pb_stab(d0, r, g)
d <- d0; for (t in 1:10) d <- d * (1 + r) / (1 + g) - pb
c(pb_stabilisant = pb, d_apres_10_ans = d)

Pièges fréquents.

  • Donner \(d\,(r-g)\) sans le facteur \(1/(1+g)\) : l’écart est faible, mais la simulation à dix ans le révèle.
  • Confondre solde primaire (hors intérêts) et solde public total (qui inclut les intérêts).
  • Utiliser un taux d’intérêt réel avec une croissance nominale : \(r\) et \(g\) doivent être exprimés de la même façon (tous deux nominaux, ou tous deux réels).

Pour aller plus loin. Trace \(pb^*\) en fonction de \(r-g\) pour des dettes de 60, 100 et 120 % du PIB : la pente vaut \(d/(1+g)\). Prolongement : que devient \(pb^*\) si le taux d’intérêt dépend lui-même du niveau de dette ?

Inflation, salaire nominal et pouvoir d’achat

Marche 1 sur 3 · Guidé

prix0 = { const g = rng("con-prix-0", salt); const p0 = g.int(100, 112), w0 = g.int(18, 30) * 100; return { p0, p1: p0 + g.int(3, 12), w0, w1: w0 + g.int(0, 8) * 50 }; }

L’indice des prix à la consommation passe de à en un an. Dans le même temps, un salaire nominal passe de € à € par mois. Calcule l’inflation, la variation du salaire nominal et la variation du pouvoir d’achat du salaire, toutes en % (valeurs exactes, pas l’approximation par différence).

AstuceIndice 1 · par où commencer

Le pouvoir d’achat d’un salaire est le salaire divisé par l’indice des prix : c’est le salaire réel. Sa variation compare le salaire réel de l’an prochain à celui de cette année.

AstuceIndice 2 · les formules

inflation = (p1/p0 - 1) * 100 ; nominal = (w1/w0 - 1) * 100 ; reel = ((w1/p1) / (w0/p0) - 1) * 100. La différence nominal - inflation n’en est qu’une approximation.

Raisonnement.

  1. Une variation en % se calcule toujours comme (valeur finale / valeur initiale − 1) × 100.
  2. Le salaire réel est \(w/p\) : il mesure ce qu’on peut acheter. Son taux de croissance est celui du rapport des deux séries.
  3. Exactement, \(1 + g_{\text{réel}} = (1 + g_{\text{nominal}})/(1 + \pi)\). La règle « nominal moins inflation » est une approximation valable quand les taux sont petits.
p0 <- prix0$p0; p1 <- prix0$p1; w0 <- prix0$w0; w1 <- prix0$w1 inflation <- (p1 / p0 - 1) * 100 nominal <- (w1 / w0 - 1) * 100 reel <- ((w1 / p1) / (w0 / p0) - 1) * 100 c(inflation = inflation, nominal = nominal, reel = reel) 
p0 <- prix0$p0; p1 <- prix0$p1; w0 <- prix0$w0; w1 <- prix0$w1
inflation <- (p1 / p0 - 1) * 100
nominal   <- (w1 / w0 - 1) * 100
reel      <- ((w1 / p1) / (w0 / p0) - 1) * 100
c(inflation = inflation, nominal = nominal, reel = reel)

Pièges fréquents.

  • Diviser le salaire par l’inflation en % au lieu de l’indice des prix.
  • Utiliser nominal - inflation : l’écart avec la valeur exacte grossit avec le niveau des taux.
  • Oublier que l’indice est en base 100 : seul le rapport p1 / p0 compte, pas le niveau.

Pour aller plus loin. La marche suivante déflate toute une série de PIB nominal et en déduit la croissance réelle.

Déflater une série : PIB réel et croissance

Marche 2 sur 3 · À compléter

prix1 = { const g = rng("con-prix-1", salt); return { seed: g.int(1, 9999), pib0: g.int(18, 30) * 100, gn: g.int(3, 6) }; }

Le PIB nominal (en milliards d’euros) vaut la première année et croît d’environ % par an en nominal (aléa tiré avec la graine ). L’inflation annuelle (4 ans) est tirée au hasard. Construis l’indice des prix (base 100 la première année), déflate le PIB, puis donne le PIB réel de la 5e année, la croissance réelle cumulée (%) et le taux de croissance réel annuel moyen (%).

AstuceIndice 1 · par où commencer

Le déflateur transforme chaque euro courant en euro de la première année : on divise par l’indice des prix et on multiplie par 100. L’indice se construit en composant les inflations successives.

AstuceIndice 2 · la formule

ip <- 100 * c(1, cumprod(1 + infl)) ; pib_reel <- pib_nom / ip * 100 ; cumul <- (pib_reel[5] / pib_reel[1] - 1) * 100 ; tcam <- ((pib_reel[5] / pib_reel[1])^(1/4) - 1) * 100.

Raisonnement.

  1. Les inflations se composent (produit), elles ne s’additionnent pas : l’indice de l’année \(t\) est \(100\prod (1+\pi_s)\).
  2. Le PIB réel est le PIB nominal divisé par l’indice (exprimé en base 1) : il retire l’effet des prix.
  3. Entre la 1re et la 5e année, il y a 4 périodes de croissance : le taux moyen est la racine quatrième du rapport, moins 1.
  4. Le taux moyen est un taux composé (moyenne géométrique), pas la moyenne arithmétique des taux annuels.
set.seed(prix1$seed) infl <- sample(0:6, 4, replace = TRUE) / 100 gn <- prix1$gn / 100 pib_nom <- prix1$pib0 * (1 + gn)^(0:4) ip <- 100 * c(1, cumprod(1 + infl)) pib_reel <- pib_nom / ip * 100 cumul <- (pib_reel[5] / pib_reel[1] - 1) * 100 tcam <- ((pib_reel[5] / pib_reel[1])^(1 / 4) - 1) * 100 c(pib_reel_5 = pib_reel[5], cumul = cumul, tcam = tcam) 
set.seed(prix1$seed)
infl <- sample(0:6, 4, replace = TRUE) / 100
gn   <- prix1$gn / 100
pib_nom <- prix1$pib0 * (1 + gn)^(0:4)
ip      <- 100 * c(1, cumprod(1 + infl))
pib_reel <- pib_nom / ip * 100
cumul <- (pib_reel[5] / pib_reel[1] - 1) * 100
tcam  <- ((pib_reel[5] / pib_reel[1])^(1 / 4) - 1) * 100
c(pib_reel_5 = pib_reel[5], cumul = cumul, tcam = tcam)

Pièges fréquents.

  • Utiliser cumsum(infl) au lieu de cumprod(1 + infl) : on additionne des taux alors qu’ils se composent.
  • Mettre l’exposant 1/5 au lieu de 1/4 : cinq années, mais quatre taux de croissance.
  • Oublier c(1, ...) : l’indice de la première année vaut 100, pas 100 × (1 + inflation).

Pour aller plus loin. Compare le taux réel calculé à la moyenne arithmétique des croissances annuelles : l’écart est faible ici, mais il grossit avec la volatilité.

Taux d’intérêt réel et valeur future du capital

Marche 3 sur 3 · Autonome

prix2 = { const g = rng("con-prix-2", salt); return { i: g.int(15, 60) / 10, pi: g.int(5, 45) / 10, K: g.int(5, 20) * 1000, T: g.int(5, 15) }; }

Tu places € pendant ans à un taux nominal de % par an, avec une inflation anticipée de % par an. Donne le taux réel exact (en %), son approximation de Fisher (i − π, en %), puis la valeur finale en euros d’aujourd’hui (pouvoir d’achat constant).

AstuceIndice 1 · par où commencer

L’équation de Fisher relie trois taux : \(1 + i = (1 + r)(1 + \pi)\). Isole \(r\). Pour le capital en euros constants, compose le taux réel sur la durée (ou déflate le capital nominal final).

AstuceIndice 2 · la formule

reel_exact = ((1 + i) / (1 + pi_a) - 1) * 100 ; fisher = (i - pi_a) * 100 ; capital_reel = K * ((1 + i) / (1 + pi_a))^T.

Raisonnement.

  1. Fisher exact : \((1+i) = (1+r)(1+\pi)\), donc \(r = (1+i)/(1+\pi) - 1\).
  2. L’approximation \(r \approx i - \pi\) néglige le terme croisé \(r\pi\) ; elle est bonne pour des taux faibles, moins pour des taux élevés.
  3. Le capital nominal final est \(K(1+i)^T\). Divisé par l’indice des prix \((1+\pi)^T\) il donne la valeur en euros d’aujourd’hui, égale à \(K(1+r)^T\).
  4. Le résultat dépend de l’inflation anticipée : le taux réel ex ante peut différer du taux réel ex post si l’inflation surprend.
i <- prix2$i / 100; pi_a <- prix2$pi / 100; K <- prix2$K; T <- prix2$T reel_exact <- ((1 + i) / (1 + pi_a) - 1) * 100 fisher <- (i - pi_a) * 100 capital_reel <- K * ((1 + i) / (1 + pi_a))^T c(reel_exact = reel_exact, fisher = fisher, capital_reel = capital_reel) 
i <- prix2$i / 100; pi_a <- prix2$pi / 100; K <- prix2$K; T <- prix2$T
reel_exact   <- ((1 + i) / (1 + pi_a) - 1) * 100
fisher       <- (i - pi_a) * 100
capital_reel <- K * ((1 + i) / (1 + pi_a))^T
c(reel_exact = reel_exact, fisher = fisher, capital_reel = capital_reel)

Pièges fréquents.

  • Calculer K * (1 + i - pi_a)^T : on retombe sur l’approximation, avec une erreur qui se compose sur T années.
  • Oublier de ramener les % en décimal (le gabarit divise par 100, mais pas ta formule si tu repars de prix2$i).
  • Confondre taux réel ex ante (inflation anticipée) et ex post (inflation constatée).

Pour aller plus loin. Fais varier l’inflation de 0 à 10 % : à partir de quel niveau l’approximation de Fisher se trompe-t-elle de plus d’un dixième de point ?

Taux de croissance annuel moyen et temps de doublement

Marche 1 sur 3 · Guidé

croi0 = { const g = rng("con-croiss-0", salt); const y0 = g.int(20, 40) * 1000, T = g.int(10, 30), r = g.pick([1, 1.5, 2, 2.5, 3]); return { y0, T, y1: Math.round(y0 * Math.pow(1 + r / 100, T)) }; }

Le PIB par habitant d’un pays passe de € à € en ans (euros constants). Calcule la croissance cumulée (%), le taux de croissance annuel moyen (%) et le nombre d’années qu’il faut, à ce rythme, pour doubler le niveau de vie.

AstuceIndice 1 · par où commencer

Une croissance annuelle \(g\) pendant \(T\) ans multiplie le niveau par \((1+g)^T\). Pour retrouver \(g\), inverse cette relation avec une racine d’ordre \(T\).

AstuceIndice 2 · la formule

tcam = ((y1 / y0)^(1 / T) - 1) * 100 ; le doublement vérifie \((1+g)^n = 2\), donc n = log(2) / log(1 + g).

Raisonnement.

  1. La croissance cumulée est simplement \(y_1/y_0 - 1\).
  2. Comme la croissance se compose, \(y_1 = y_0(1+g)^T\) et \(g = (y_1/y_0)^{1/T} - 1\).
  3. Temps de doublement : \((1+g)^n = 2 \Rightarrow n = \ln 2/\ln(1+g)\). La « règle de 70 » (\(n \approx 70/g\) en %) en est une bonne approximation.
  4. La croissance du niveau de vie par habitant est ce qui compte pour comparer les pays dans le temps, pas la croissance du PIB total.
y0 <- croi0$y0; y1 <- croi0$y1; T <- croi0$T cumul <- (y1 / y0 - 1) * 100 tcam <- ((y1 / y0)^(1 / T) - 1) * 100 doublement <- log(2) / log(1 + tcam / 100) c(cumul = cumul, tcam = tcam, doublement = doublement) 
y0 <- croi0$y0; y1 <- croi0$y1; T <- croi0$T
cumul      <- (y1 / y0 - 1) * 100
tcam       <- ((y1 / y0)^(1 / T) - 1) * 100
doublement <- log(2) / log(1 + tcam / 100)
c(cumul = cumul, tcam = tcam, doublement = doublement)

Pièges fréquents.

  • Diviser la croissance cumulée par T : cela donne une moyenne arithmétique qui surestime le taux composé.
  • Oublier de convertir tcam en décimal avant log(1 + .).
  • Appliquer la règle de 70 à un taux élevé (> 5 %) : elle devient imprécise.

Pour aller plus loin. Compare la règle de 70 (70 / tcam) avec la valeur exacte pour un taux de 1 %, 3 % et 8 %.

Convergence : quand un pays pauvre rattrape-t-il ?

Marche 2 sur 3 · À compléter

Un pays pauvre a un PIB par habitant de € et croît de % par an. Un pays riche a € et croît de % par an. Combien d’années faut-il pour que le pays pauvre rattrape le pays riche (ratio = 1) ? Quel est le ratio pauvre / riche après 30 ans ?

AstuceIndice 1 · par où commencer

Écris l’égalité des deux niveaux au bout de \(n\) ans, puis passe aux logarithmes pour sortir \(n\) de l’exposant.

AstuceIndice 2 · la formule

\(n\,[\ln(1+g_p) - \ln(1+g_r)] = \ln(b_0/a_0)\) ; en R : log(b0 / a0) / (log(1 + gp) - log(1 + gr)). Le ratio à 30 ans : a0 * (1 + gp)^30 / (b0 * (1 + gr)^30).

Raisonnement.

  1. Rattrapage : \(a_0(1+g_p)^n = b_0(1+g_r)^n\).
  2. En passant aux logarithmes, \(n = \ln(b_0/a_0)\,/\,[\ln(1+g_p) - \ln(1+g_r)]\). Il n’a de sens que si \(g_p > g_r\).
  3. Le ratio après 30 ans multiplie le ratio initial par \(((1+g_p)/(1+g_r))^{30}\) : même sans rattrapage complet, il peut fortement monter.
  4. C’est la convergence inconditionnelle : elle suppose que le pays pauvre maintient durablement son avance de croissance, ce qui est loin d’être acquis (piège du revenu intermédiaire).

Pièges fréquents.

  • Écrire log(b0 / a0) / (gp - gr) : l’écart de taux sans logarithmes sous-estime la durée.
  • Inverser b0 / a0 : le logarithme serait négatif.
  • Supposer que le rattrapage est garanti : il dépend de l’écart de croissance maintenu, qui se réduit souvent avec le développement.

Comptabilité de la croissance : le rôle de la PGF

croi2 = { const g = rng("con-croiss-2", salt); return { gy: g.int(15, 35) / 10, gk: g.int(15, 45) / 10, gl: g.int(0, 15) / 10, alpha: g.pick([0.3, 0.33, 0.35]) }; }

Sur une période, le PIB croît de % par an, le stock de capital de % et l’emploi de %. La part du capital dans la valeur ajoutée est . Avec une fonction de production Cobb-Douglas à rendements constants, calcule la contribution du capital, celle du travail, la croissance de la productivité globale des facteurs (PGF, résidu de Solow) et la part de la croissance expliquée par la PGF (en %).

AstuceIndice 1 · par où commencer

En Cobb-Douglas, la croissance de la production se décompose en \(g_Y = g_A + \alpha g_K + (1-\alpha) g_L\). La PGF \(g_A\) est ce qui reste une fois retirées les contributions des facteurs.

AstuceIndice 2 · la formule

contrib_K = a * gk ; contrib_L = (1 - a) * gl ; pgf = gy - contrib_K - contrib_L ; part_pgf = pgf / gy * 100.

Raisonnement.

  1. On part de \(Y = A K^{\alpha} L^{1-\alpha}\) et on passe en logarithmes puis en variations : \(g_Y = g_A + \alpha g_K + (1-\alpha) g_L\).
  2. Chaque facteur contribue à hauteur de sa part de revenu multipliée par sa croissance (hypothèse de concurrence : les parts de revenu mesurent les élasticités).
  3. La PGF est un résidu : elle capte tout ce qui n’est pas mesuré (progrès technique, organisation, mais aussi erreurs de mesure des facteurs).
  4. Sa part dans la croissance est le rapport \(g_A/g_Y\) ; elle peut dépasser 100 % ou être négative si les facteurs croissent plus ou moins vite que la production.
gy <- croi2$gy; gk <- croi2$gk; gl <- croi2$gl; a <- croi2$alpha contrib_K <- a * gk contrib_L <- (1 - a) * gl pgf <- gy - contrib_K - contrib_L part_pgf <- pgf / gy * 100 c(contrib_K = contrib_K, contrib_L = contrib_L, pgf = pgf, part_pgf = part_pgf)

  • Pondérer le capital par 1 - a : a est la part du capital.
  • Sommer gk + gl sans pondération : les facteurs ne contribuent pas à parts égales.
  • Interpréter la PGF comme « le progrès technique » : c’est un résidu, qui absorbe aussi les erreurs de mesure et la qualité des facteurs.

Dans la population de 15 à 64 ans (effectif : milliers), il y a milliers de personnes en emploi et milliers de chômeurs au sens du BIT. Calcule le taux de chômage, le taux d’activité et le taux d’emploi, en %.

AstuceIndice 1 · par où commencer

Les trois taux n’ont pas le même dénominateur. Le chômage se rapporte aux actifs, l’activité et l’emploi à la population en âge de travailler. Les actifs sont les personnes en emploi plus les chômeurs.

AstuceIndice 2 · la formule

actifs = E + U ; chomage = U / actifs * 100 ; activite = actifs / N * 100 ; emploi = E / N * 100.

Raisonnement.

  1. Actifs (force de travail) = occupés + chômeurs. Les inactifs (étudiants, retraités, découragés) n’en font pas partie.
  2. Taux de chômage = chômeurs / actifs, et non / population totale.
  3. Taux d’activité = actifs / population en âge de travailler ; taux d’emploi = occupés / même population.
  4. Le taux de chômage peut baisser parce que des chômeurs sortent de l’activité (découragement) : le taux d’emploi donne une lecture complémentaire.

actifs   <- E + U
chomage  <- U / actifs * 100
activite <- actifs / N * 100
emploi   <- E / N * 100
c(chomage = chomage, activite = activite, emploi = emploi)

Pièges fréquents.

  • Diviser les chômeurs par la population totale : on obtient la part de chômeurs dans la population, pas le taux de chômage.
  • Compter les inactifs parmi les chômeurs : il faut chercher activement et être disponible.
  • Comparer deux pays sur le seul taux de chômage sans regarder le taux d’emploi.

Flux d’emploi et chômage d’équilibre

Marche 2 sur 3 · À compléter

trav1 = { const g = rng("con-trav-1", salt); return { s: g.int(8, 15) / 10, f: g.int(15, 35), u0: g.int(7, 12) }; }

Chaque mois, % des personnes en emploi perdent leur poste (taux de séparation s) et % des chômeurs retrouvent un emploi (taux de sortie f). Le taux de chômage initial est de %. Calcule le taux de chômage d’équilibre, puis le taux de chômage après 12 mois en simulant la dynamique mensuelle (la population active est constante).

AstuceIndice 1 · par où commencer

À l’équilibre, les entrées au chômage égalent les sorties : \(s(1-u) = f\,u\). Pour la dynamique, chaque mois le chômage augmente des séparations et diminue des retours à l’emploi.

AstuceIndice 2 · la formule

u_star = s / (s + f) * 100 ; u <- u + s * (1 - u) - f * u à chaque mois (les flux s’appliquent à l’emploi \(1-u\) et au chômage \(u\)).

Raisonnement.

  1. Flux entrants : \(s(1-u)\) ; flux sortants : \(f\,u\). L’équilibre impose \(u^* = s/(s+f)\).
  2. La dynamique est \(u_{t+1} = u_t + s(1-u_t) - f\,u_t = (1-s-f)u_t + s\) : elle converge vers \(u^*\) à la vitesse \(s+f\) par mois.
  3. Le taux d’équilibre est faible quand les séparations sont rares ou quand le retour à l’emploi est rapide : deux marchés du travail à même taux de chômage peuvent avoir des flux très différents.
  4. C’est le cadre de la courbe de Beveridge et des modèles d’appariement.
s <- trav1$s / 100; f <- trav1$f / 100; u <- trav1$u0 / 100 u_star <- s / (s + f) * 100 for (mois in 1:12) { u <- u + s * (1 - u) - f * u } c(u_star = u_star, u_12 = u * 100)

u_star <- s / (s + f) * 100
for (mois in 1:12) {
  u <- u + s * (1 - u) - f * u
}
c(u_star = u_star, u_12 = u * 100)

Pièges fréquents.

  • Appliquer s à toute la population au lieu de l’emploi (1 - u).
  • Mélanger pourcentages et décimaux : u doit rester en décimal dans la boucle.
  • Conclure que le chômage d’équilibre est « naturel » ou souhaitable : il dépend des institutions et des chocs.

Loi d’Okun : estimer le lien croissance-chômage

trav2 = { const g = rng("con-trav-2", salt); return { seed: g.int(1, 9999), beta: g.pick([0.3, 0.4, 0.5]), gstar: g.pick([1.2, 1.5, 2]) }; }

On observe 40 années de croissance du PIB (g, en %) et de variation du taux de chômage (du, en points). La loi d’Okun s’écrit du = −β (g − g) : g est la croissance qui stabilise le chômage. Les données sont simulées avec la graine . Estime β et g* par une régression de du sur g, et donne le R².

AstuceIndice 1 · par où commencer

Estime lm(du ~ g) : l’ordonnée à l’origine vaut \(\beta g^*\) et la pente vaut \(-\beta\). Il faut donc retourner la relation pour en tirer \(\beta\) et \(g^*\).

AstuceIndice 2 · la formule

fit <- lm(du ~ g) ; a <- coef(fit)[1] ; b <- coef(fit)[2] ; beta = -b ; gstar = a / beta (car \(a = \beta g^*\)) ; r2 = summary(fit)$r.squared.

Raisonnement.

  1. En développant \(du = -\beta g + \beta g^*\) : une droite de pente \(-\beta\) et d’ordonnée à l’origine \(\beta g^*\).
  2. On estime par MCO : \(\hat b\) (pente) et \(\hat a\) (constante). Alors \(\hat\beta = -\hat b\) et \(\hat g^* = \hat a/\hat\beta\).
  3. Le R² mesure la part de la variance de \(du\) expliquée par \(g\) ; ici il est élevé car les données sont simulées avec peu de bruit.
  4. Dans les données réelles la relation est instable (elle varie selon les pays, les périodes et les institutions du marché du travail) ; on ne l’interprète pas comme causale.
set.seed(trav2$seed) g <- rnorm(40, 1.8, 1.6) du <- -trav2$beta * (g - trav2$gstar) + rnorm(40, 0, 0.25) fit <- lm(du ~ g) a <- unname(coef(fit)[1]); b <- unname(coef(fit)[2]) beta <- -b c(beta = beta, gstar = a / beta, r2 = summary(fit)$r.squared)

Règle de Taylor : quel taux directeur ?

Marche 1 sur 3 · Guidé

La banque centrale vise une inflation de 2 %. Le taux réel neutre est de %, l’inflation observée de % et l’écart de production (output gap) de % du PIB potentiel. Avec la règle de Taylor (coefficients 0,5 et 0,5), quel taux directeur nominal est préconisé ? Quel taux réel implique-t-il ?

AstuceIndice 1 · par où commencer

La règle part du taux réel neutre plus l’inflation (pour ne pas changer le taux réel), puis ajoute deux corrections : une réaction à l’écart d’inflation et une réaction à l’écart de production.

AstuceIndice 2 · la formule

\(i = r^* + \pi + 0{,}5(\pi - \pi^*) + 0{,}5\,\text{gap}\) ; en R : rstar + pi + 0.5 * (pi - pistar) + 0.5 * gap. Le taux réel implicite est i_taylor - pi.

Raisonnement.

  1. Si l’inflation est à la cible et l’écart de production nul, le taux nominal vaut \(r^* + \pi^*\) : politique neutre.
  2. Coefficient 0,5 sur l’écart d’inflation : le taux nominal monte de plus d’un point quand l’inflation monte d’un point (principe de Taylor), donc le taux réel augmente et freine la demande.
  3. Coefficient 0,5 sur l’écart de production : la banque refroidit une économie en surchauffe (gap > 0) et soutient une économie déprimée.
  4. Le taux réel implicite \(i - \pi = r^* + 0{,}5(\pi-\pi^*) + 0{,}5\,\text{gap}\) dépasse \(r^*\) si l’économie surchauffe : politique restrictive.
rstar <- mon0$rstar; pi <- mon0$pi; gap <- mon0$gap; pistar <- 2 i_taylor <- rstar + pi + 0.5 * (pi - pistar) + 0.5 * gap r_implicite <- i_taylor - pi c(i_taylor = i_taylor, r_implicite = r_implicite) 
rstar <- mon0$rstar; pi <- mon0$pi; gap <- mon0$gap; pistar <- 2
i_taylor    <- rstar + pi + 0.5 * (pi - pistar) + 0.5 * gap
r_implicite <- i_taylor - pi
c(i_taylor = i_taylor, r_implicite = r_implicite)

Pièges fréquents.

  • Oublier d’ajouter l’inflation pi : on obtiendrait un taux réel, pas un taux nominal.
  • Confondre pi (l’inflation observée, un nombre ici) avec la constante mathématique pi de R : on la redéfinit volontairement dans le gabarit.
  • Ignorer que rstar et le gap sont non observables et estimés avec incertitude : la règle donne un ordre de grandeur.

AstuceIndice 1 · par où commencer

Définis une petite fonction mensualite(K, taux, annees). Une mensualité constante \(M\) vérifie \(K = M\,\dfrac{1-(1+r)^{-m}}{r}\) où \(r\) est le taux mensuel et \(m\) le nombre de mois.

AstuceIndice 2 · la formule

mensualite <- function(K, taux, annees) { r <- taux / 12; m <- 12 * annees; K * r / (1 - (1 + r)^(-m)) } ; surcoût total = (M1 - M0) * m.

Raisonnement.

  1. Le capital emprunté est la valeur actualisée des mensualités : \(K = M\sum_{t=1}^{m}(1+r)^{-t} = M\,\dfrac{1-(1+r)^{-m}}{r}\).
  2. D’où \(M = K\,r/(1-(1+r)^{-m})\), avec \(r = i/12\) et \(m = 12n\).
  3. En définissant une fonction, on réutilise exactement le même calcul pour les deux taux : moins d’erreurs de copier-coller.
  4. Le canal du crédit est un mécanisme de transmission : +1 point de taux augmente la mensualité de plusieurs % et réduit donc la demande de logement et de crédit.

Solde courant = épargne − investissement

comm0 = { const g = rng("con-comm-0", salt); const X = g.int(30, 45) * 10; return { C: g.int(55, 62) * 10, G: g.int(18, 25) * 10, I: g.int(20, 26) * 10, X, M: X + g.int(-6, 6) * 10 }; }

Une économie ouverte (milliards d’euros) a une consommation privée de , des dépenses publiques de , un investissement de , des exportations de et des importations de . Calcule le PIB (identité comptable), l’épargne nationale S = PIB − C − G, le solde commercial et vérifie que S − I est égal au solde commercial (on néglige les revenus primaires). Donne aussi le solde en % du PIB.

AstuceIndice 1 · par où commencer

Le PIB est la somme des demandes finales : consommation, investissement, dépenses publiques, plus les exportations nettes. Les ressources non consommées (ni par les ménages, ni par l’État) sont l’épargne nationale.

AstuceIndice 2 · la formule

Y = C + I + G + X - M ; S = Y - C - G ; solde = X - M. Substitue Y dans S pour voir apparaître \(S - I = X - M\).

Raisonnement.

  1. Identité du revenu : \(Y = C + I + G + (X - M)\).
  2. L’épargne nationale est \(S = Y - C - G\). En remplaçant \(Y\) : \(S = I + (X - M)\), donc \(S - I = X - M\).
  3. Un pays dont l’épargne dépasse l’investissement a un excédent extérieur : il prête au reste du monde. Un pays qui investit plus qu’il n’épargne s’endette envers l’étranger.
  4. L’identité est comptable : elle ne dit pas ce qui cause quoi (une hausse du déficit public n’a pas un effet mécanique unique sur le solde).
C <- comm0$C; G <- comm0$G; I <- comm0$I; X <- comm0$X; M <- comm0$M Y <- C + I + G + X - M S <- Y - C - G solde <- X - M c(PIB = Y, S_moins_I = S - I, solde = solde, solde_pct_PIB = solde / Y * 100)

Pièges fréquents.

  • Calculer le PIB sans retrancher M : on compterait deux fois des biens produits à l’étranger.
  • Oublier que le solde est en % du PIB, pas des exportations.
  • Interpréter l’identité comme une relation causale : S − I = X − M tient toujours, mais ne dit rien sur le sens de causalité.

Taux de change réel et compétitivité

comm1 = { const g = rng("con-comm-1", salt); return { e0: g.int(90, 130) / 100, e1: g.int(80, 140) / 100, pi: g.int(0, 40) / 10, pistar: g.int(0, 40) / 10 }; }

Le taux de change nominal e est le prix d’une unité de monnaie étrangère en monnaie nationale (e monte = dépréciation de la monnaie nationale). Il passe de à en un an. L’inflation nationale est de %, l’inflation étrangère de %. Les niveaux de prix valent 1 la première année dans les deux pays. Calcule le taux de change réel q = e P*/P les deux années et sa variation (%). Une hausse de q est un gain de compétitivité-prix.

AstuceIndice 1 · par où commencer

Le taux de change réel corrige le taux nominal des écarts d’inflation : il compare le prix des biens étrangers (convertis en monnaie nationale) au prix des biens nationaux.

AstuceIndice 2 · la formule

q0 = e0 * 1 / 1 ; q1 = e1 * Pstar1 / P1 ; variation_pct = (q1 / q0 - 1) * 100.

Raisonnement.

  1. \(q = eP^*/P\) : le numérateur est le prix étranger exprimé en monnaie nationale, le dénominateur le prix national.
  2. Une dépréciation nominale (e monte) augmente q ; une inflation nationale plus forte que l’inflation étrangère diminue q (perte de compétitivité-prix).
  3. L’effet nominal et l’effet des prix peuvent se compenser : un pays peut se déprécier sans gagner en compétitivité s’il a plus d’inflation.
  4. La variation de q se lit comme \((1+\Delta e)(1+\pi^*)/(1+\pi) - 1\).
e0 <- comm1$e0; e1 <- comm1$e1; P1 <- 1 + comm1$pi / 100; Pstar1 <- 1 + comm1$pistar / 100 q0 <- e0 * 1 / 1 q1 <- e1 * Pstar1 / P1 c(q0 = q0, q1 = q1, variation_pct = (q1 / q0 - 1) * 100)

Pièges fréquents.

  • Inverser P et P* : le taux de change réel serait lu à l’envers (une hausse deviendrait une perte de compétitivité).
  • Utiliser l’inflation en % directement dans le produit : il faut 1 + pi / 100.
  • Oublier la convention du taux nominal (prix de la devise étrangère) : avec la convention inverse, le sens de lecture s’inverse.

Condition de Marshall-Lerner : une dépréciation améliore-t-elle le solde ?

Les exportations et les importations valent 100 (commerce équilibré). La monnaie nationale se déprécie de %. Les prix des exportations en monnaie nationale ne changent pas ; leurs volumes augmentent de ε_x × d avec ε_x = . Les prix des importations en monnaie nationale augmentent de d ; leurs volumes baissent de ε_m × d avec ε_m = . Calcule le nouveau solde commercial exact, sa variation, la somme des élasticités et indique (1 ou 0) si la condition de Marshall-Lerner (somme > 1) est vérifiée.

AstuceIndice 1 · par où commencer

Exprime exportations et importations en monnaie nationale après la dépréciation : valeur = prix × volume. Les exportations n’ont qu’un effet volume, les importations ont un effet prix (défavorable) et un effet volume (favorable).

AstuceIndice 2 · la formule

X1 = X0 * (1 + ex * d) ; M1 = M0 * (1 + d) * (1 - em * d) ; solde = X1 - M1 ; la variation vaut solde - (X0 - M0) ; ML = as.numeric(ex + em > 1).

Raisonnement.

  1. Valeur des exportations (monnaie nationale) : prix inchangé × volume \((1+\varepsilon_x d)\).
  2. Valeur des importations : prix \((1+d)\) × volume \((1-\varepsilon_m d)\).
  3. Au premier ordre, avec commerce équilibré, \(\Delta(X-M) \approx M_0\,d\,(\varepsilon_x + \varepsilon_m - 1)\) : la dépréciation améliore le solde si \(\varepsilon_x + \varepsilon_m > 1\) (condition de Marshall-Lerner).
  4. À court terme, les élasticités sont faibles (contrats en cours, prix rigides) : le solde peut se dégrader d’abord puis s’améliorer (courbe en J). Le calcul exact ci-dessus inclut aussi un petit terme du second ordre.
ex <- comm2$ex; em <- comm2$em; d <- comm2$d / 100; X0 <- 100; M0 <- 100 X1 <- X0 * (1 + ex * d) M1 <- M0 * (1 + d) * (1 - em * d) c(solde = X1 - M1, variation = (X1 - M1) - (X0 - M0), somme_elast = ex + em, ML = as.numeric(ex + em > 1))

Pièges fréquents.

  • Oublier l’effet prix sur les importations : on conclurait toujours à une amélioration.
  • Appliquer la hausse de prix d aux exportations : leur prix en monnaie nationale est supposé fixe.
  • Lire la condition comme exacte : avec le terme du second ordre, le signe peut différer quand la somme est proche de 1.
