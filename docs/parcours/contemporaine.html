rng = {
  // Générateur pseudo-aléatoire reproductible : graine = jour + id d'exercice + salt.
  // (Source unique : scripts/test_exercices.R évalue cette même cellule avec Node.)
  const today = new Date().toISOString().slice(0, 10);
  const hash = (s) => {
    let h = 1779033703 ^ s.length;
    for (let i = 0; i < s.length; i++) { h = Math.imul(h ^ s.charCodeAt(i), 3432918353); h = (h << 13) | (h >>> 19); }
    return h >>> 0;
  };
  const mulberry32 = (a) => () => {
    a |= 0; a = (a + 0x6d2b79f5) | 0;
    let t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
  return (id, salt = 0, day = today) => {
    const u = mulberry32(hash(`${day}|${id}|${salt}`));
    const int = (a, b) => a + Math.floor(u() * (b - a + 1));
    const pick = (arr) => arr[Math.floor(u() * arr.length)];
    const normal = () => Math.sqrt(-2 * Math.log(1 - u())) * Math.cos(2 * Math.PI * u());
    return { u, int, pick, normal };
  };
}

Un an de dette : l’effet boule de neige

Marche 1 sur 3 · Guidé

dette0 = { const g = rng("con-dette-0", salt); return { d0: g.int(60, 120), r: g.pick([1, 2, 3, 4]), g: g.pick([0, 1, 2, 3]), pb: g.int(-3, 2) }; }

La dette publique représente % du PIB. Le taux d’intérêt nominal moyen est de %, la croissance nominale du PIB de % et le solde primaire de % du PIB (positif = excédent). Calcule la part de la variation du ratio due à l’écart entre le taux d’intérêt et la croissance (effet boule de neige), puis le ratio de l’année suivante.

AstuceIndice 1 · par où commencer

Pars de la récurrence \(d' = d\,(1+r)/(1+g) - pb\) et isole le terme qui dépend de l’écart \(r - g\) du reste.

AstuceIndice 2 · la formule

\((1+r)/(1+g) = 1 + (r-g)/(1+g)\), donc boule \(= d_0\,(r-g)/(1+g)\) et \(d_1 = d_0 + \text{boule} - pb\).

Raisonnement.

  1. En niveau, la dette grossit des intérêts : \(D' = (1+r)D - PB\). Le PIB grossit de \(g\) ; le ratio devient \(d' = \dfrac{1+r}{1+g}\,d - pb\).
  2. On sépare l’effet de l’écart \(r-g\) : comme \(\dfrac{1+r}{1+g} = 1 + \dfrac{r-g}{1+g}\), on obtient \(d' = d + \dfrac{r-g}{1+g}\,d - pb\).
  3. Le terme \(\dfrac{r-g}{1+g}\,d\) est l’effet boule de neige. Si \(r > g\), la dette gonfle même sans déficit primaire ; si \(r < g\), elle se dilue spontanément.
  4. Le solde primaire est en points de PIB : un excédent (\(pb > 0\)) se retranche directement du ratio.
d0 <- dette0$d0; r <- dette0$r / 100; g <- dette0$g / 100; pb <- dette0$pb boule <- d0 * (r - g) / (1 + g) # effet boule de neige d1 <- d0 + boule - pb # = d0 * (1 + r) / (1 + g) - pb c(boule = boule, d1 = d1) 
d0 <- dette0$d0; r <- dette0$r / 100; g <- dette0$g / 100; pb <- dette0$pb
boule <- d0 * (r - g) / (1 + g)       # effet boule de neige
d1 <- d0 + boule - pb                 # = d0 * (1 + r) / (1 + g) - pb
c(boule = boule, d1 = d1)

Pièges fréquents.

  • Garder \(r\) et \(g\) en pourcentage : le terme serait cent fois trop grand.
  • Oublier le dénominateur \(1+g\) : pour de faibles taux l’écart est minime, mais l’identité exacte l’inclut.
  • Inverser le signe du solde primaire : un excédent réduit la dette.

Pour aller plus loin. La marche suivante répète ce calcul sur dix ans.

Dynamique de la dette publique

Marche 2 sur 3 · À compléter

dette1 = { const g = rng("con-dette-1", salt); return { d0: g.int(60, 120), r: g.pick([1, 2, 3, 4]), g: g.pick([0, 1, 2, 3]), pb: g.int(-3, 2) }; }

La dette publique représente % du PIB. Le taux d’intérêt nominal moyen est de %, la croissance nominale du PIB de % et le solde primaire de % du PIB (positif = excédent). Simule 10 ans d’évolution du ratio dette/PIB avec la récurrence : d(t+1) = d(t) × (1 + r) / (1 + g) − pb.

AstuceIndice 1 · par où commencer

C’est un calcul récursif : la dette de l’année suivante dépend de celle de l’année en cours. Écris d’abord le passage de \(t\) à \(t+1\), puis répète-le dix fois avec une boucle.

AstuceIndice 2 · la formule

Le premier terme est l’effet « boule de neige » : si \(r > g\) il fait croître le ratio même sans nouveau déficit primaire. Le solde primaire est exprimé en points de PIB : il se retranche directement.

Raisonnement.

  1. En niveau, la dette s’accroît des intérêts et diminue de l’excédent primaire : \(D_{t+1} = (1+r)\,D_t - PB_t\).
  2. Le PIB nominal croît de \(g\) : \(Y_{t+1} = (1+g)\,Y_t\).
  3. En divisant, le ratio suit \(d_{t+1} = d_t\,\dfrac{1+r}{1+g} - pb\).
  4. Décomposition : \(d_{t+1} - d_t = \dfrac{r-g}{1+g}\,d_t - pb\) : un effet « boule de neige » moins le solde primaire.
  5. On itère dix fois avec une boucle : chaque ligne utilise la valeur de la ligne précédente (d[t]). À long terme le ratio se stabilise à \(d^* = \dfrac{(1+g)\,pb}{r-g}\) si \(r>g\) et \(pb>0\).
d0 <- dette1$d0; r <- dette1$r / 100; g <- dette1$g / 100; pb <- dette1$pb d <- numeric(11); d[1] <- d0 for (t in 1:10) d[t + 1] <- d[t] * (1 + r) / (1 + g) - pb c(d_final = d[11], variation = d[11] - d0) 
d0 <- dette1$d0; r <- dette1$r / 100; g <- dette1$g / 100; pb <- dette1$pb
d <- numeric(11); d[1] <- d0
for (t in 1:10) d[t + 1] <- d[t] * (1 + r) / (1 + g) - pb
c(d_final = d[11], variation = d[11] - d0)

Pièges fréquents.

  • Mettre \(r\) et \(g\) en pourcentage (2 au lieu de 0,02) : le gabarit les convertit déjà.
  • Écrire d0 au lieu de d[t] dans la boucle : la dette ne « s’accumule » plus.
  • Lire \(pb > 0\) comme un déficit : ici un solde primaire positif est un excédent, qui réduit la dette.

Pour aller plus loin. La marche suivante inverse la question : quel solde primaire maintient le ratio constant ?

Solde primaire stabilisant

Marche 3 sur 3 · Autonome

dette2 = { const g = rng("con-dette-2", salt); return { d0: g.int(60, 120), r: g.pick([1, 2, 3, 4]), g: g.pick([0, 1, 2, 3]) }; }

La dette représente % du PIB, avec un taux d’intérêt nominal de % et une croissance nominale de %. Écris la fonction pb_stab(d, r, g) qui donne le solde primaire (en points de PIB) maintenant le ratio constant, puis vérifie par simulation sur 10 ans.

AstuceIndice 1 · par où commencer

Un ratio stable signifie \(d_{t+1} = d_t\). Écris cette égalité dans la récurrence \(d_{t+1} = d_t\,(1+r)/(1+g) - pb\) et isole \(pb\).

AstuceIndice 2 · la formule

\(pb^* = d\left(\dfrac{1+r}{1+g} - 1\right) = d\,\dfrac{r-g}{1+g}\).

Raisonnement.

  1. On veut \(d_{t+1} = d_t = d\) : \(d\,\dfrac{1+r}{1+g} - pb = d\).
  2. D’où \(pb^* = d\left(\dfrac{1+r}{1+g} - 1\right) = d\,\dfrac{r-g}{1+g}\).
  3. Lecture : stabiliser le ratio coûte d’autant plus que la dette est élevée et que l’écart \(r-g\) est grand. Si \(r < g\), le solde primaire stabilisant est négatif : on peut supporter un déficit primaire sans que le ratio monte.
  4. La simulation confirme : avec \(pb^*\), le ratio reste exactement à \(d_0\) après dix ans.
  5. \(pb^*\) ne fait que stabiliser : pour réduire le ratio, il faut un solde primaire supérieur.
d0 <- dette2$d0; r <- dette2$r / 100; g <- dette2$g / 100 pb_stab <- function(d, r, g) d * (r - g) / (1 + g) # stabilisation : d_{t+1} = d_t pb <- pb_stab(d0, r, g) d <- d0; for (t in 1:10) d <- d * (1 + r) / (1 + g) - pb c(pb_stabilisant = pb, d_apres_10_ans = d) 
d0 <- dette2$d0; r <- dette2$r / 100; g <- dette2$g / 100
pb_stab <- function(d, r, g) d * (r - g) / (1 + g)     # stabilisation : d_{t+1} = d_t
pb <- pb_stab(d0, r, g)
d <- d0; for (t in 1:10) d <- d * (1 + r) / (1 + g) - pb
c(pb_stabilisant = pb, d_apres_10_ans = d)

Pièges fréquents.

  • Donner \(d\,(r-g)\) sans le facteur \(1/(1+g)\) : l’écart est faible, mais la simulation à dix ans le révèle.
  • Confondre solde primaire (hors intérêts) et solde public total (qui inclut les intérêts).
  • Utiliser un taux d’intérêt réel avec une croissance nominale : \(r\) et \(g\) doivent être exprimés de la même façon (tous deux nominaux, ou tous deux réels).

Pour aller plus loin. Trace \(pb^*\) en fonction de \(r-g\) pour des dettes de 60, 100 et 120 % du PIB : la pente vaut \(d/(1+g)\). Prolongement : que devient \(pb^*\) si le taux d’intérêt dépend lui-même du niveau de dette ?
