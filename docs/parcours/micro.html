  const hash = (s) => {
    let h = 1779033703 ^ s.length;
    for (let i = 0; i < s.length; i++) { h = Math.imul(h ^ s.charCodeAt(i), 3432918353); h = (h << 13) | (h >>> 19); }
    return h >>> 0;

    a |= 0; a = (a + 0x6d2b79f5) | 0;

Laboratoire : comparer les structures de marché

Demande linéaire \(P = A - bQ\) et coût marginal constant \(c\) (sans coût fixe). Fais varier les paramètres et compare prix, quantités, surplus et perte sèche entre concurrence, monopole, Cournot et Stackelberg.

NoteCe qu’il faut observer
  • Le prix suit l’ordre concurrence < Stackelberg < Cournot (N = 2) < monopole, et la quantité l’ordre inverse.
  • Quand \(N\) augmente, Cournot tend vers la concurrence parfaite.
  • La perte sèche est le triangle entre la demande et le coût marginal, à droite de la quantité produite.

Offre d’une firme preneuse de prix

Marche 1 sur 3 · Guidé

micro1 = { const g = rng("micro-cpp-1", salt); const a = g.int(2, 8); return { a, F: g.int(20, 60), p: a + g.int(6, 20) }; }

Une firme preneuse de prix a pour coût total C(q) = 0,5 q² + q + et le prix de marché est p = . Calcule la quantité qui maximise son profit et ce profit.

AstuceIndice 1 · par où commencer

Une firme preneuse de prix choisit la quantité \(q\) qui maximise \(\pi(q) = pq - C(q)\). Écris la condition du premier ordre en mots avant de la mettre en formule : à l’optimum, le prix doit égaler le coût de la dernière unité produite.

AstuceIndice 2 · la formule

Dérive \(C(q)\) : \(C'(q) = q + a\). Pose \(p = C'(q)\) et résous en \(q\). Le profit est \(pq - C(q)\).

Raisonnement.

  1. La firme est preneuse de prix : \(p\) est une donnée, seule la quantité \(q\) est choisie.
  2. Profit : \(\pi(q) = pq - C(q)\). Condition du premier ordre : \(p = C'(q)\) (la recette marginale d’une firme preneuse de prix est \(p\)).
  3. Ici \(C'(q) = q + a\), donc \(q^* = p - a\).
  4. Condition du second ordre : \(C''(q) = 1 > 0\), le coût marginal est croissant, c’est bien un maximum.
  5. Le profit se calcule en remplaçant \(q^*\) dans \(pq - C(q)\), sans oublier le coût fixe \(F\) : il peut être négatif tout en étant supérieur à \(-F\), auquel cas la firme produit quand même à court terme.
a <- micro1$a; F <- micro1$F; p <- micro1$p q_star <- p - a profit <- p * q_star - (0.5 * q_star^2 + a * q_star + F) c(q = q_star, profit = profit) 
a <- micro1$a; F <- micro1$F; p <- micro1$p
q_star <- p - a
profit <- p * q_star - (0.5 * q_star^2 + a * q_star + F)
c(q = q_star, profit = profit)

Pièges fréquents.

  • Oublier \(F\) dans le profit : on conclut à tort que la firme gagne de l’argent.
  • Résoudre \(p = CM(q)\) (coût moyen) au lieu de \(p = Cm(q)\) (coût marginal) : le coût moyen sert à décider d’entrer ou sortir, pas de combien produire.
  • Conclure qu’un profit négatif impose de fermer : à court terme, la firme produit tant que le prix couvre le coût variable (voir la marche suivante).

Pour aller plus loin. Trace \(\pi(q)\) sur une grille de valeurs de \(q\) et vérifie que son sommet est bien en \(q^*\). Puis passe à la marche suivante : que devient la décision de la firme quand \(p\) devient très bas ?

Offre de court terme et seuil de fermeture

Marche 2 sur 3 · À compléter

cpp3 = { const g = rng("micro-cpp-3", salt); return { a: g.int(2, 8), F: g.pick([18, 32, 50, 72]) }; }

Une firme preneuse de prix a pour coût total C(q) = 0,5 q² + q + . Le coût fixe est d’abord irrécupérable (court terme : la firme ne peut pas le récupérer en fermant), puis évitable (long terme : elle peut quitter le marché). Écris les deux fonctions d’offre et compare-les sur une grille de prix.

AstuceIndice 1 · par où commencer

Dans les deux cas, quand la firme produit, \(q = p - a\). Seule la condition « produit-elle ? » change. Pour la trouver, demande-toi ce que la firme perd si elle ferme.

AstuceIndice 2 · la formule

Court terme : fermer fait perdre exactement \(F\) (irrécupérable) ; produire rapporte un profit variable \(\tfrac12(p-a)^2 \ge 0\) dès que \(p \ge a\). Long terme : fermer fait gagner \(0\) ; la firme produit seulement si \(\pi = \tfrac12(p-a)^2 - F \ge 0\), soit \(p \ge a + \sqrt{2F}\).

Raisonnement.

  1. Quand elle produit, la firme égalise \(p\) et \(Cm(q) = q + a\) : \(q = p - a\). La vraie question est : produit-elle ?
  2. Court terme. \(F\) est payé quoi qu’il arrive. Produire \(q = p - a\) rapporte un profit variable \(\tfrac12(p-a)^2\), positif dès que \(p > a\) ; fermer ne rapporte rien. Donc elle produit pour tout \(p \ge a\) (minimum du coût variable moyen, le « seuil de fermeture »), soit \(q = \max(p-a,\,0)\). Sa perte totale peut être négative (jusqu’à \(-F\)) sans qu’elle ferme.
  3. Long terme. \(F\) est évitable : la firme n’est active que si \(\pi = \tfrac12(p-a)^2 - F \ge 0\), soit \(p \ge a + \sqrt{2F}\) (minimum du coût moyen, le « seuil de rentabilité »). Sous ce prix, l’offre est nulle.
  4. L’offre de long terme présente un saut : elle passe de 0 à la production \(\sqrt{2F}\) au prix \(a + \sqrt{2F}\). Entre \(a\) et ce seuil, la firme produit à court terme en perdant de l’argent, ce que le long terme ne tolère pas.
a <- cpp3$a; F <- cpp3$F offre_ct <- function(p) { if (p >= a) p - a else 0 # seuil de fermeture : p = a } offre_lt <- function(p) { if (p >= a + sqrt(2 * F)) p - a else 0 # seuil de rentabilité : p = a + sqrt(2F) } prix <- seq(0.25, 30, by = 2.5) rbind(court = sapply(prix, offre_ct), long = sapply(prix, offre_lt))

Pièges fréquents.

  • Fermer dès que le profit total est négatif à court terme : tant que \(p\) couvre le coût variable, produire réduit la perte.
  • Utiliser le coût moyen total pour la décision de court terme : seul le coût moyen variable compte quand \(F\) est irrécupérable.
  • Écrire p - a sans condition : sous le seuil on obtiendrait une production négative.

Pour aller plus loin. Repère sur un graphique le seuil de fermeture (\(p = a\)) et le seuil de rentabilité (\(p = a + \sqrt{2F}\)). La marche suivante s’appuie sur ce second seuil pour trouver le prix et le nombre de firmes de long terme.

Équilibre de long terme et nombre de firmes

Marche 3 sur 3 · À compléter

micro2 = {
  const g = rng("micro-cpp-2", salt);
  const s = g.pick([4, 6, 8, 10]);                       // s = sqrt(2F), caché
  const a = g.int(2, 6), b = g.int(2, 4), N0 = g.int(10, 40);
  return { a, F: s * s / 2, b, D0: b * (a + s) + N0 * s };
}

Dans une industrie en concurrence parfaite avec libre entrée, toutes les firmes ont le coût C(q) = 0,5 q² + q + . La demande de marché est Q = − p. Trouve l’équilibre de long terme : prix, production par firme et nombre de firmes.

AstuceIndice 1 · par où commencer

À long terme deux conditions tiennent en même temps : la libre entrée pousse le profit à zéro, et la concurrence fait produire chaque firme là où prix = coût marginal. Ensemble, elles fixent la production d’une firme. Commence par elle.

AstuceIndice 2 · la formule

Le minimum de \(CM(q) = 0{,}5\,q + a + F/q\) se trouve en annulant sa dérivée : \(0{,}5 - F/q^2 = 0\). Ensuite \(p = CM(q_{lr})\), \(Q = D_0 - b\,p\) et \(N = Q / q_{lr}\).

Raisonnement.

  1. Libre entrée : profit nul, donc \(p = CM(q)\).
  2. Concurrence : \(p = Cm(q)\). Les deux conditions imposent \(Cm(q) = CM(q)\), ce qui n’arrive qu’au minimum du coût moyen.
  3. \(CM(q) = 0{,}5\,q + a + F/q\) ; \(CM'(q) = 0{,}5 - F/q^2 = 0\) donne \(q = \sqrt{2F}\) (échelle efficace minimale).
  4. Prix de long terme : \(p = CM_{\min} = a + \sqrt{2F}\), indépendant de la demande.
  5. La demande de marché fixe seulement la quantité totale : \(Q = D_0 - b\,p\), d’où \(N = Q/q\). (En pratique on arrondit \(N\) à l’entier inférieur ; l’énoncé est construit pour que \(N\) soit entier.)
a <- micro2$a; F <- micro2$F; b <- micro2$b; D0 <- micro2$D0 q_lr <- sqrt(2 * F) p_lr <- a + sqrt(2 * F) Q_lr <- D0 - b * p_lr N_lr <- Q_lr / q_lr c(p = p_lr, q = q_lr, N = N_lr) 
a <- micro2$a; F <- micro2$F; b <- micro2$b; D0 <- micro2$D0
q_lr <- sqrt(2 * F)
p_lr <- a + sqrt(2 * F)
Q_lr <- D0 - b * p_lr
N_lr <- Q_lr / q_lr
c(p = p_lr, q = q_lr, N = N_lr)

Pièges fréquents.

  • Résoudre \(p = Cm(q)\) sans imposer le profit nul : on obtient la production de court terme, pas celle de long terme.
  • Diviser la demande de marché par \(N\) avant de connaître \(N\) : \(N\) est justement l’inconnue.
  • Penser que la demande influence le prix de long terme : avec libre entrée et des coûts identiques, l’offre de long terme est horizontale, seul \(N\) s’ajuste.

Pour aller plus loin. Que devient le prix si la demande double ? Rien : c’est \(N\) qui double. Reprends la marche précédente pour retrouver le seuil \(p = a + \sqrt{2F}\) sur la courbe d’offre.

Recette totale et recette marginale

Marche 1 sur 4 · Guidé

micro0 = { const g = rng("micro-mono-0", salt); return { A: g.int(40, 100), b: g.pick([1, 2, 3]), Q: g.int(3, 9) }; }

La demande inverse d’un monopole est P = − Q. Pour la quantité Q = , calcule le prix, la recette totale et la recette marginale, puis vérifie la recette marginale par un calcul numérique (vendre 0,001 unité de plus).

AstuceIndice 1 · par où commencer

Trois grandeurs s’enchaînent : le prix se lit sur la demande, la recette totale est prix × quantité, et la recette marginale est la variation de la recette totale quand on vend une unité de plus.

AstuceIndice 2 · les formules

\(P = A - bQ\) ; \(R = P \times Q\) ; \(R_m = dR/dQ = A - 2bQ\). Le calcul numérique du gabarit doit donner à peu près la même chose (il diffère de \(bh\)).

Raisonnement.

  1. Le prix se lit sur la demande : \(P = A - bQ\).
  2. La recette totale est \(R(Q) = P \times Q = AQ - bQ^2\).
  3. La recette marginale est sa dérivée : \(R_m(Q) = A - 2bQ\). Elle part du même point que la demande mais descend deux fois plus vite : pour vendre une unité de plus, le monopole doit baisser le prix, et cette baisse s’applique à toutes les unités déjà vendues.
  4. Le calcul numérique confirme : \([R(Q+h) - R(Q)]/h \approx R_m\) (l’écart est de \(-bh\)).
  5. Conséquence : \(R_m < P\) dès que \(Q > 0\). C’est la source du pouvoir de marché : le monopole ne retire de la dernière unité que \(R_m\), pas \(P\).
A <- micro0$A; b <- micro0$b; Q <- micro0$Q P <- A - b * Q R <- P * Q Rm <- A - 2 * b * Q h <- 0.001 Rm_num <- ((A - b * (Q + h)) * (Q + h) - R) / h c(P = P, R = R, Rm = Rm, Rm_num = Rm_num) 
A <- micro0$A; b <- micro0$b; Q <- micro0$Q
P  <- A - b * Q
R  <- P * Q
Rm <- A - 2 * b * Q
h <- 0.001
Rm_num <- ((A - b * (Q + h)) * (Q + h) - R) / h
c(P = P, R = R, Rm = Rm, Rm_num = Rm_num)

Pièges fréquents.

  • Confondre recette marginale et prix : pour une firme en concurrence parfaite elles coïncident, pas pour un monopole.
  • Oublier le 2 : \(R_m = A - bQ\) serait la demande elle-même.
  • Dériver par rapport à \(P\) au lieu de \(Q\).

Pour aller plus loin. Cherche la quantité où \(R_m\) s’annule : c’est le maximum de la recette totale. La marche suivante égalise \(R_m\) au coût marginal pour trouver l’équilibre du monopole.

Monopole et perte sèche

Marche 2 sur 4 · À compléter

micro3 = { const g = rng("micro-mono-1", salt); const b = g.pick([1, 2, 4]), c = g.int(2, 10), k = g.int(5, 15); return { A: c + 2 * b * k, b, c }; }

Un monopole fait face à la demande inverse P = − Q avec un coût total C(Q) = Q. Calcule l’équilibre de monopole, son profit et la perte sèche par rapport à la concurrence parfaite.

AstuceIndice 1 · par où commencer

Un monopole choisit la quantité et laisse la demande fixer le prix. Il compare ce que lui rapporte la dernière unité vendue (recette marginale) à ce qu’elle lui coûte (coût marginal).

AstuceIndice 2 · la formule

\(R_m = A - 2bQ = c\) donne \(Q_m = (A-c)/(2b)\). Remplace dans la demande pour \(P_m\). La quantité concurrentielle résout \(A - bQ = c\).

Raisonnement.

  1. \(R(Q) = (A - bQ)\,Q\) ; en dérivant, \(R_m(Q) = A - 2bQ\) : pour vendre une unité de plus il faut baisser le prix de toutes les unités, d’où une pente deux fois plus forte que celle de la demande.
  2. Condition de premier ordre : \(R_m = c\), donc \(Q_m = (A-c)/(2b)\).
  3. Le prix se lit sur la demande (pas sur \(R_m\)) : \(P_m = A - bQ_m = (A+c)/2\).
  4. Profit : \((P_m - c)\,Q_m\).
  5. Référence concurrentielle : \(P = c\) donne \(Q_c = (A-c)/b = 2Q_m\). Le monopole produit la moitié de la quantité concurrentielle.
  6. Perte sèche : triangle de base \(Q_c - Q_m\) et de hauteur \(P_m - c\), soit \(\tfrac12 (P_m-c)(Q_c-Q_m) = (A-c)^2/(8b)\).
A <- micro3$A; b <- micro3$b; c <- micro3$c Q_m <- (A - c) / (2 * b) P_m <- A - b * Q_m profit <- (P_m - c) * Q_m Q_c <- (A - c) / b dwl <- 0.5 * (P_m - c) * (Q_c - Q_m) c(Q = Q_m, P = P_m, profit = profit, DWL = dwl) 
A <- micro3$A; b <- micro3$b; c <- micro3$c
Q_m <- (A - c) / (2 * b)
P_m <- A - b * Q_m
profit <- (P_m - c) * Q_m
Q_c <- (A - c) / b
dwl <- 0.5 * (P_m - c) * (Q_c - Q_m)
c(Q = Q_m, P = P_m, profit = profit, DWL = dwl)

Pièges fréquents.

  • Lire le prix sur la courbe de recette marginale : elle donne la valeur de la dernière unité pour le monopole, pas le prix payé.
  • Oublier le facteur 2 dans \(R_m = A - 2bQ\) (on retombe sur la demande).
  • Prendre le profit pour la perte sèche : le profit est un transfert du consommateur vers le producteur ; seul le triangle est détruit pour la société.

Pour aller plus loin. Vérifie que ta perte sèche vaut \((A-c)^2/(8b)\), puis fais varier \(c\) dans le laboratoire en haut de page. La marche suivante passe à plusieurs firmes.

Duopole de Cournot : meilleures réponses

Marche 3 sur 4 · À compléter

micro5 = { const g = rng("micro-cournot-0", salt); return { A: g.int(60, 120), b: g.int(1, 3), c: g.int(5, 20) }; }

Deux firmes de coût marginal c = se font concurrence en quantités sur la demande P = − Q. Écris la fonction de meilleure réponse, puis laisse les deux firmes s’ajuster tour à tour jusqu’à l’équilibre et compare avec la formule fermée.

AstuceIndice 1 · par où commencer

La meilleure réponse maximise \(\big(A - b(q_1 + q_2) - c\big)\,q_1\) par rapport à \(q_1\), avec \(q_2\) donné. Dérive, annule, isole \(q_1\) en fonction de \(q_2\).

AstuceIndice 2 · les formules

\(q_1 = \dfrac{A - c - b\,q_2}{2b}\). À l’équilibre symétrique \(q_1 = q_2 = q\), donc \(3bq = A - c\), soit \(q = \dfrac{A-c}{3b}\).

Raisonnement.

  1. La firme 1 prend \(q_2\) comme donné : \(\pi_1 = (A - b(q_1+q_2) - c)\,q_1\).
  2. Condition du premier ordre : \(A - bq_2 - 2bq_1 - c = 0\), d’où la meilleure réponse \(q_1 = \dfrac{A - c - bq_2}{2b}\). Elle est décroissante : si l’autre produit plus, je produis moins.
  3. Un équilibre de Nash est un point fixe des deux meilleures réponses. La boucle l’atteint car la pente de la meilleure réponse vaut \(-1/2\) : chaque tour divise l’erreur par 2 (60 tours suffisent largement).
  4. Par symétrie \(q_1 = q_2 = q\) : \(q = \dfrac{A-c-bq}{2b}\), donc \(q^* = \dfrac{A-c}{3b}\).
  5. Production totale : \(2(A-c)/(3b)\), soit les deux tiers de la quantité concurrentielle \((A-c)/b\) (un cartel produirait la moitié, la concurrence parfaite le tout).
A <- micro5$A; b <- micro5$b; c <- micro5$c br <- function(q_autre) (A - c - b * q_autre) / (2 * b) q1 <- 0; q2 <- 0 for (k in 1:60) { q1 <- br(q2); q2 <- br(q1) } q_formule <- (A - c) / (3 * b) c(q1 = q1, q2 = q2, formule = q_formule) 
A <- micro5$A; b <- micro5$b; c <- micro5$c
br <- function(q_autre) (A - c - b * q_autre) / (2 * b)
q1 <- 0; q2 <- 0
for (k in 1:60) { q1 <- br(q2); q2 <- br(q1) }
q_formule <- (A - c) / (3 * b)
c(q1 = q1, q2 = q2, formule = q_formule)

Pièges fréquents.

  • Oublier de diviser par \(2b\) : on ignore l’effet de sa propre quantité sur le prix.
  • Croire que l’équilibre est le monopole partagé : chaque firme ignore l’effet de sa quantité sur le profit de l’autre, d’où une production totale supérieure à celle du cartel.
  • Mélanger q_autre et sa propre quantité dans br : la fonction ne doit dépendre que de la quantité de l’adversaire.

Pour aller plus loin. La marche suivante généralise à \(N\) firmes avec une fonction de \(N\) ; pour \(N=2\) on doit retrouver \((A-c)/(3b)\). Essaie d’autres points de départ pour \(q_1, q_2\) : l’équilibre ne change pas.

Cournot à N firmes : prix d’équilibre

Marche 4 sur 4 · Autonome

micro4 = { const g = rng("micro-cournot-1", salt); return { A: g.int(60, 120), b: g.int(1, 3), c: g.int(5, 20) }; }

N firmes identiques, de coût marginal constant c = et sans coût fixe, se font concurrence en quantités (Cournot) sur le marché de demande P = − Q. Écris la fonction cournot_price(N) qui renvoie le prix d’équilibre, puis évalue-la pour N = 1, …, 6.

AstuceIndice 1 · par où commencer

Écris d’abord le problème d’une firme en prenant la quantité des autres comme donnée, puis impose la symétrie : toutes les firmes produisent la même quantité \(q\). Le résultat sera une fonction de \(N\).

AstuceIndice 2 · la formule

La condition de premier ordre de la firme \(i\) est \(A - bQ - b q_i = c\). Avec \(Q = N q\) et des firmes symétriques : \(A - c = b(N+1) q\).

Raisonnement.

  1. Profit de la firme \(i\) : \(\big(A - b(q_i + Q_{-i}) - c\big)\,q_i\).
  2. Condition du premier ordre : \(A - bQ_{-i} - 2bq_i = c\), d’où la meilleure réponse \(q_i = (A - c - bQ_{-i})/(2b)\).
  3. Symétrie : \(Q_{-i} = (N-1)q\) et \(q_i = q\), donc \((N+1)\,b\,q = A - c\) et \(q = \dfrac{A-c}{(N+1)b}\).
  4. Quantité totale \(Q = Nq = \tfrac{N}{N+1}\,Q_c\), prix \(P = A - bQ = \dfrac{A + Nc}{N+1}\).
  5. Contrôles : \(N=1\) redonne le monopole \((A+c)/2\) ; quand \(N\to\infty\), \(P\to c\) (concurrence parfaite).

Pièges fréquents.

  • Écrire \(q_i = (A-c)/(2b)\) : on oublie la réaction aux autres firmes (c’est la quantité de monopole).
  • Remplacer \(Q\) par \(q\) au lieu de \(Nq\) dans la demande.
  • Confondre \(N+1\) et \(N\) : le « +1 » vient de la dérivée de \(q_i^2\) (la firme internalise l’effet de sa propre quantité sur le prix).

Pour aller plus loin. Ajoute le profit par firme \((P-c)q\) et la perte sèche pour \(N = 1, \dots, 6\) : elle décroît comme \(1/(N+1)^2\). Compare avec le laboratoire en haut de page.
